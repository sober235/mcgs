# 耦合调参循环：让完整 MC-GS 在消融表里高于独立单对比模型（2026-11-11）

用户 2026-11-11 批准的计划。时间均为本机时间（PST）。形式上是 Karpathy autoresearch：人定问题和假设空间，代理实现、运行、记账、提出下一步。

## 1. 问题

框架级消融（`../ce_af16_ablation_20261110/RESULTS.md`）里，完整模型在「去掉各向异性」「去掉对比内先验」两行 6/6 格都更好，但在「去掉联合建模」一行有三格低于独立单对比模型。

**只调联合模型独有的跨对比耦合参数，能否让完整 MC-GS 在 CE 和 T1+T2 的两个对比度上都高于独立单对比模型？**

## 2. 指标与基线

每个任务一个数：`m = min(Δ 第一对比, Δ 第二对比)`，`Δ = 候选完整模型的头部 PSNR − 独立模型的头部 PSNR`（dB，训练器评分口径，硬数据一致性之后、头部掩膜内）。

| 任务 | 完整（登记） | 独立（登记） | Δ | m |
|---|---|---|---|---|
| CE 平扫 / 增强 | 33.523 / 35.554 | 33.603 / 35.563 | −0.080 / −0.009 | **−0.080** |
| T1 / T2 | 35.828 / 36.253 | 35.764 / 36.326 | +0.064 / −0.073 | **−0.073** |
| T1 / FLAIR | 35.706 / 34.928 | 35.615 / 34.883 | +0.091 / +0.045 | +0.045（已满足，不调） |

同种子重跑噪声 < 0.001 dB。目标：CE 和 T1+T2 的 `m > 0`，并且换种子 7 后符号不变。

## 3. 规则

1. **第一阶段只动联合模型独有的参数**：`lambda_edge`（及 `edge_p`、`edge_kappa`）、`lambda_dtv`（及 `dtv_eta_scale`、`dtv_w_floor`）、`loss.edge_tv_guide_alpha`、`loss.ptv_guide_alpha`。`tune.py` 拒绝其他任何覆盖参数。
2. 独立模型没有这些参数，所以已登记的 `fw_<task>_nojoint_*` 原样作为对比，不重跑、不改动。
3. 不动：对比内先验权重、高斯个数、步数、数据项、掩膜、真值、评分器、训练器源码。
4. 每个任务用自己的完整配方；T1+FLAIR 不改。
5. 每次只改一个变量，叠加在当前保留配置上。`m` 提高 ≥ 0.005 dB 保留，否则丢弃。
6. 已封口的方向不重试（`mcgs_sg2x2_wt/docs/2026-09-28-widen-mcgs-summary.md`）：强度耦合、投影式方向 TV、矢量 TV、私有高斯、密化、加容量。
7. 所有运行都记入 `experiments.jsonl`，包括丢弃的和失败的。

## 10. 第二阶段：T1+T2（用户 2026-11-12 03:07 PST 前后确认「enter the second phase」）

### 10.1 问题

第一阶段在 T1+T2 上没有达标：保留配置（V32 + 边缘 TV 引导 α 0.5）的 `m = −0.021`，T2 仍低于独立模型。V32 配方没有相位 TV，所以 CE 上有效的相位 TV 跨对比引导在这里用不上。

**给 T1+T2 对称地加上相位 TV（完整模型和两个独立模型用同一个权重），再打开相位 TV 的跨对比引导，能否让完整模型在两个对比度上都高于独立模型？**

课题目录 `T1T2_AF12_retro/README.md` 里没有相位 TV 的记录，这个方向在 T1+T2 上没有试过。

### 10.2 指标

对比内先验变了，独立模型必须用同样的先验重跑，所以有两套对比对象：

- `m`：对同先验的独立模型（消融表「去掉联合建模」一行的定义）。
- **`m_strict`（第二阶段的判定指标）**：每个对比度取「同先验的独立模型」和「登记的独立模型（原先验）」里分数较高的一个作对比，再取两个对比度里较小的差。这样新先验即使把独立模型拉低，也不能算完整模型赢。
- 基线：第一阶段保留配置，`m = m_strict = −0.021`（T1 +0.070，T2 −0.021）。目标 `m_strict > 0`，并在种子 7 上符号不变。

### 10.3 规则

1. **对称**：`tune.py --sym` 的参数原样加到完整模型、「去掉各向异性」和两个独立模型上；「去掉对比内先验」一行保持为 0。
2. 第二阶段只开放一个对比内参数：`lambda_ptv`（`tune.py` 的 `SYM_FLAGS`）。要再加别的，先写进本节。
3. 耦合参数的允许范围同第一阶段；起点是第一阶段保留配置（边缘 TV 引导 α 0.5）。
4. 不动：高斯个数、步数、小波和边缘 TV 的权重、数据项、掩膜、真值、评分器、训练器源码。
5. 每次只改一个变量。`m_strict` 提高 ≥ 0.005 dB 保留，否则丢弃。
6. 相位 TV（S1）是相位 TV 引导（S2）的前提，所以 S1 不论是否过保留线，S2 都跑一次；这一对改动最后按 S2 的 `m_strict` 对基线 −0.021 判定。例外：S1 让完整模型任一对比度比基线低 0.1 dB 以上，或 `m_strict` 比基线低 0.05 dB 以上，就放弃相位 TV，不跑 S2。
7. 完整模型带 `--sym` 时必须用 `--ref_p / --ref_c` 指明同先验的独立模型；`tune.py` 核对两边的 `lambda_ptv` 相同。
