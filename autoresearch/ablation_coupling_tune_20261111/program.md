# 耦合调参循环：让完整 MC-GS 在消融表里高于独立单对比模型（2026-11-11）

用户 2026-11-11 批准的计划。时间均为本机时间（PST）。形式上是 Karpathy autoresearch：人定问题和假设空间，代理实现、运行、记账、提出下一步。

## 1. 问题

框架级消融（`../ce_af16_ablation_20261110/RESULTS.md`）里，完整模型在「去掉各向异性」「去掉对比内先验」两行 6/6 格都更好，但在「去掉联合建模」一行有三格低于独立单对比模型。

**只调联合模型独有的跨对比耦合参数，能否让完整 MC-GS 在 CE 和 T1+T2 的两个对比度上都高于独立单对比模型？**

## 2. 指标与基线

每个任务一个数：`m = min(Δ 第一对比, Δ 第二对比)`，`Δ = 候选完整模型的头部 PSNR − 独立模型的头部 PSNR`（dB，训练器评分口径，硬数据一致性之后、头部掩膜内）。

| 任务 | 完整（登记） | 独立（登记） | Δ | m |
|---|---|---|---|---|
| CE 平扫 / 增强 | 33.523 / 35.554 | 33.603 / 35.563 | −0.080 / −0.009 | **−0.080** |
| T1 / T2 | 35.828 / 36.253 | 35.764 / 36.326 | +0.064 / −0.073 | **−0.073** |
| T1 / FLAIR | 35.706 / 34.928 | 35.615 / 34.883 | +0.091 / +0.045 | +0.045（已满足，不调） |

同种子重跑噪声 < 0.001 dB。目标：CE 和 T1+T2 的 `m > 0`，并且换种子 7 后符号不变。

## 3. 规则

1. **第一阶段只动联合模型独有的参数**：`lambda_edge`（及 `edge_p`、`edge_kappa`）、`lambda_dtv`（及 `dtv_eta_scale`、`dtv_w_floor`）、`loss.edge_tv_guide_alpha`、`loss.ptv_guide_alpha`。`tune.py` 拒绝其他任何覆盖参数。
2. 独立模型没有这些参数，所以已登记的 `fw_<task>_nojoint_*` 原样作为对比，不重跑、不改动。
3. 不动：对比内先验权重、高斯个数、步数、数据项、掩膜、真值、评分器、训练器源码。
4. 每个任务用自己的完整配方；T1+FLAIR 不改。
5. 每次只改一个变量，叠加在当前保留配置上。`m` 提高 ≥ 0.005 dB 保留，否则丢弃。
6. 已封口的方向不重试（`mcgs_sg2x2_wt/docs/2026-09-28-widen-mcgs-summary.md`）：强度耦合、投影式方向 TV、矢量 TV、私有高斯、密化、加容量。
7. 所有运行都记入 `experiments.jsonl`，包括丢弃的和失败的。

## 4. 假设队列

| 任务 | 第一轮 | 第二轮 |
|---|---|---|
| CE（基线 P3：`lambda_edge` 0.001，无其他耦合项） | C1 `lambda_edge` 0；C2 `lambda_dtv` 0.01；C3 边缘 TV 引导 α 0.25；C4 相位 TV 引导 α 0.25 | 对保留下来的参数各做一档增减 |
| T1+T2（基线 V32：无耦合项，无相位 TV） | T1 `lambda_edge` 0.001；T2 `lambda_dtv` 0.01；T3 边缘 TV 引导 α 0.25 | 同上 |

依据：这组参数是 9 月 widen 轮次在 T1+FLAIR 上把公平余量做到 +0.106 / +0.064 dB 的那一组。

## 5. 停止条件

- 达到目标并跑完第二轮；
- 同一任务连续 3 次没有新的保留配置：停下报告，不自行扩大搜索范围；
- 每个任务最多 8 次训练；
- 任何失败、NaN、撞卡。

第一阶段达不到目标就如实报告。第二阶段（对称地改对比内先验，需要重跑独立模型和全部四个配置）要用户另行确认。

## 6. 收尾（只对找到新保留配置的任务）

1. 用新配方重跑「去掉各向异性」「去掉对比内先验」，确认完整模型仍高于两者。
2. 种子 7 复核：完整模型和两个独立模型各一次。
3. `../ce_af16_ablation_20261110/RESULTS.md` 新增一节，原有表格和结论不删不改。

## 7. 运行

```
gpu.py run --gpu 2 -- @python autoresearch/ablation_coupling_tune_20261111/tune.py \
    --task ce --name c1_edge0 "--ov=--lambda_edge 0" "--hyp=common-edge prior off"
```

- 代码基线与框架级消融相同：`codex_artifacts/mcgs_framework_ablation_20261110/trainer`（源 54f8a2a），`tune.py` 启动时逐文件核对，并核对未加覆盖参数的命令与登记的 `fw_` 运行逐项相同。
- 输出：同一目录的 `trainer/results_arc/tn_<task>_<name>*`；账本 `tune/experiments.jsonl`。
- GPU 2、7 为授权显卡；卡上有其他用户的进程时不共用。
- 分支 `exp/ablation-coupling-tune-20261111`，每轮一次提交，不自动推送。

## 8. 限定

- 调参用的是同一个受试者的真值评分；即使达标，结论只能写成「在这个受试者上、耦合项调过之后」。
- T1+FLAIR 上的记录显示耦合项对余量的影响在 0.1 dB 以内，天花板探针不超过 0.3 dB；不保证成功。
- 独立模型按消融设计沿用完整模型的对比内先验，没有单独调参。
