# CE AF16 平扫 + 增强：延长训练预算 / 学习率调度 autoresearch（2026-10-31 ~ 11-01）

Karpathy autoresearch（`karpathy/autoresearch@228791f`）的改编版本，接续 `autoresearch_1031` 分支的密度控制叠加实验。
单病例 CE 平扫（pre）+ 增强（post），256×232×176，42 线圈，AF16（历史 vdPoisMex mask），10 个固定对比方法，
固定评分器 `evaluate.py`（只用 PSNR / SSIM / NMSE）。这是单病例自适应开发，不是独立测试集结论。

## 设定

- **主判据 S6**：59 个病灶切面中最好的同一切面上，pre 和 post 的 PSNR/SSIM/NMSE 六项相对全部 10 个对手的最小归一化裕量。S6 > 0 即严格胜出。整脑分数（WH）为补充指标。
- **搜索方向**：只改 stage2（tv1125_wav075，从 4500 步接续）的训练步数、学习率衰减 gamma、整体学习率倍数 `lr_scale`、几何参数学习率倍数 `geo_lr_scale`。
- **可改文件**：每个候选一个 `recipes/<exp>.json`；`recipe.json` 为当前 keeper。`long_chain.py` 是固定 harness。
- **噪声控制**：每个候选在两个种子底座（seed 42 = i1_ctrl、seed 7 = b1s7_ctrl 的 4500 步检查点）上各跑一次，按里程碑导出并评分。两种子均值 S6 超过当前 keeper 0.0001 以上才保留。同配方换种子的 S6 波动约 0.0012。
- **一致性**：冒烟测试前 4 步 loss 与原 keeper 链逐位一致；L1 的 500 步里程碑复现原对照（ΔS6 ≈ 0）。

## 结论

1. 学习率方向累计把两种子均值 S6 从 −0.0234 提高到 −0.0205（+0.0029），每轮增益在递减（+0.0014 → +0.0012 → +0.0004）。
2. 规律：更低的学习率 + 较早停止有利于病灶切面 S6；更长训练继续提高整脑分数，但 S6 在 1000–1500 步后回落。几何学习率加大有害。
3. 距离 S6 > 0 还差约 0.02，远大于单轮增益，学习率调度方向接近饱和，需要换方向（例如允许小的 loss / DC 改动）。
