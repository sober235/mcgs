# UIH 3D 膝关节 T1 / T2 / PD k 空间：采样检查、读出方向分层图、T1 与 PD 对比度比较（2026-11-25）

来自会话 "Experiments on different body parts"。用户先问项目里有没有脑以外部位的实验，随后选定 amax 上的
UIH 3D 膝关节多对比度 k 空间数据，要求查清它是否全采样，并按读出方向查看 T1、PD 的 k 空间和图像分层。
用户 2026-11-25："No need for raw data; only k-space is required."

本目录只有 CPU 上的数据检查和看图，没有做重建或训练。

## 1. 采样检查（48 个文件）

脚本 `audit_sampling.py`，结果 `audit.tsv` / `audit.json`。

| 对比度 | 没有采集的部分 | 结论 |
|---|---|---|
| T1、PD（16 人） | 只有椭圆外的四个角，占相位编码平面 15–19%；椭圆内没有空缺 | 椭圆内全采样，口径与 Stanford 3D FSE 膝相同 |
| T2（S01–S15） | 四个角，加上一个相位编码方向一侧的部分傅里叶条带（S01：n3 轴 176 行里约 20 行）；合计 20–25%，其中椭圆内缺 4–7% | 不是全采样 |

例外两个文件：

- **S10 PD：** 导出格式不同。网格 480 × 240 × 210，读出 2 倍过采样，四角是严格的零；同样只缺四角，
  但网格和这个人的 T1、T2（210 × 166 × 186）对不上。
- **S16 T2：** 没有缺角，而是 n3 轴两端共缺约 18%（196 行中 22 + 12 行）；读出方向沿 n0 轴，
  和这个人的 T1、PD 不同。

所有文件都满足：

- 奇数行和偶数行用相邻行预测，误差相同，说明没有并行成像补出来的行；
- 外缘没有用共轭对称填充；
- 未采集位置不是严格的零，而是很小的非零值（S10 PD 除外）。

S01 T2 和 S16 T2 的未采集位置分布另外用 SSH 只读检查画成了文本图核对过，与上表一致。

## 2. 读出方向分层图（S01 的 T1、PD）

脚本 `fig_readout_layers.py`，输出在 `figures/`：

- `uih_knee_S01_t1_pd_readout_layers.pdf`：完整图；
- `..._preview.jpg`：预览；
- `..._legend.txt`：图注；
- `..._params.json`：参数和源文件 sha256。

600 dpi PNG 只保存在本地和服务器上，不进 Git。

图的内容：

- **a、b 行：** T1、PD 的 k 空间，线圈平方和，显示 log10(|k| / max)。
- **c、d 行：** T1、PD 的图像。逆 3D FFT 后做线圈平方和，每个对比度除以自己的 99.5% 分位数。
- **第 1 列：** 沿读出方向切开的截面，红线标出右边五层的位置。
- **第 2–6 列：** 垂直于读出方向的五层。k 空间层在 kx = −64、−16、0、+16、+64；
  图像层在 x = 27、58、88、118、149（共 176）。

读出方向是膝关节的左右方向：垂直于读出的各层是矢状面，读出截面是冠状面。数组按原样显示，没有旋转或翻转。

服务器副本在 `~/codex_artifacts/mcgs_uih_knee_readout_layers_20261125/`，已用 sha256 校验，
和本地的 `figures/SHA256SUMS` 一致。

## 3. T1 与 PD 的对比度比较

用户看图后觉得 T1 和 PD 的对比度一样。检查代码是 `contrast_check.py`，当时通过 SSH 只读运行，
原样输出在 `contrast_check_output.txt`。

对 S01、S05、S12 做了定量比较，用 T2 作对比度确实不同的参照：

| | T1 与 PD | T2 与 PD |
|---|---|---|
| 对数强度相关系数 r | 0.87–0.95 | 0.77–0.87 |
| 各类组织的强度比（k-means 聚成 5 类） | 0.73–1.07 | 0.37–1.19 |

- **结论：** T1 和 PD 的对比度确实很接近。
- **标签没有标反：** 最暗的一类组织（推测主要是肌肉）在 T1 上比在 PD 上暗 20–27%，方向符合 T1 加权，只是加权很弱。
- **原因是推测：** 可能是 3D 快速自旋回波序列本身削弱了 T1 加权。没有 TR、TE 可查，未能确认。

各对比度对齐到 PD 所需的整数体素平移（梯度互相关）：

| 人 | T1 → PD | T2 → PD |
|---|---|---|
| S01 | [−1, 0, 0] | 0 |
| S05 | 0 | [−1, −1, −1] |
| S12 | 0 | [0, −1, 1] |

其余 13 人还没有查。

## 用于 MC-GS 实验时

- **欠采样掩膜：** 只能在每个文件实际采集的区域里抽取。加速倍数要报两个口径：按整个相位编码平面，和按实采区域。
- **对比度组合：** T1+PD 两个都是椭圆内全采样，但对比度相近；PD+T2 对比度差别大，但 T2 不是全采样。
- **联合训练器：** 一次只接两个网格相同的对比度，用之前要先按上表做平移对齐。
