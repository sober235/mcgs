## 1. 为什么换数据

框架消融的 T1+T2 任务原来用 huangyuwei（`T1T2_AF12_retro`）。对齐探针测得该对数据中 T2 相对 T1 沿读出方向偏约 1 个体素（NMI −1.30，NGF −0.60），FLAIR 对照不偏。共享几何的联合模型假设两种对比已配准，偏移会直接压低联合模型的 T2。

用户要求（2026-11-13）：换一对新的 T1W / T2W 数据，不能有体素偏移。

## 4. 消融训练（2026-11-13）

### 4.1 运行

- 6 个训练，每张卡一个，GPU 2–7。每张卡启动前都做了两次间隔 75 秒的空卡检查。
- 本机时间：03:31–03:36 PST 启动，04:00–04:30 PST 由本机轮询看到结束，全部退出码 0。
- 脚本：`abl_framework.py --rows <row>`，任务 `t1t2tb` 和 `t1t2tbv32`，提交 `329547a`，快照 digest `5e609259df8e…`。
- 输出：服务器 `codex_artifacts/mcgs_framework_ablation_20261110/trainer/results_arc/fw_t1t2tb_*`、`fw_t1t2tbv32_full*`。
- 配方原样沿用，没有在 tangbing 上调任何参数：
  - 完整模型 = V32 + 边缘 TV 跨对比引导 α 0.5，这是在 huangyuwei 上调出的第一阶段保留配置；
  - 去掉各向异性、去掉对比内先验，用同一配方；
  - 独立模型 = V32（单对比训练器不接受跨对比引导）；
  - 另跑一个 V32 原配方的完整模型作对照。
- 4000 步，种子 42，每个模型 240 万个高斯。

### 4.3 读法

1. **目标没有达到。** 完整模型优于「去掉各向异性」和「去掉对比内先验」，两个对比度、四项指标全部成立。但「去掉联合建模」一行，独立模型在两个对比度的 PSNR 上都更高：
   - T1 +0.065，T2 +0.123；
   - SSIM 和 NMSE 也是独立模型略好；
   - HFEN 是完整模型略好：T1 0.1103 对 0.1122，T2 0.1028 对 0.1029。
2. **用 V32 原配方作完整模型也不行。**
   - T1 与独立模型持平（−0.004 dB），SSIM 和 HFEN 是完整模型略好；
   - T2 仍低 0.104 dB。
3. **对齐之后，联合模型的 T2 仍然落后。**
   - 在已对齐的 tangbing 上，独立模型的 T2 比完整模型高 0.123（保留配置）/ 0.104（V32）。
   - huangyuwei 上对应是 0.021 / 0.073。但这是两个受试者之间的比较，不能据此说对齐让差距变大。
   - 能说的只是：在一对已对齐的数据上，T2 的落后依然存在。所以体素偏移不是它的主因。
   - 这与 9 月 `T1T2_AF12_retro` README 的记录一致。那时还没有提出偏移假设，联合对单对比在 v2 下就是 T1 +0.30 / T2 −0.25，v3 下是 +0.09 / −0.12。当时的解释是：共享几何的点数由 T1 卡住（T1 在 1.2M 左右达到峰值，再加点会过拟合；T2 单独要到 2.4M 才饱和），T2 为 T1 的增益付代价。
4. **在 huangyuwei 上调出的边缘 TV 引导没有迁移过来。** 在 tangbing 上它比 V32 原配方低 0.061 / 0.019 dB。说明第一阶段在单一受试者上调出的小幅增益（≤ 0.05 dB 量级），有一部分是贴合该受试者的。
5. 各向异性在这个受试者上的作用比 huangyuwei 上大得多（−0.35 / −0.50 dB，huangyuwei 上是 −0.07 / −0.12）。

**撤回的建议（2026-11-13，用户追问后核查）。** 我在报告里曾建议跑一个 480 万高斯的完整模型，来检验「容量不够」。核查后撤回，理由有三：

1. **前提错了。** 两边每个对比度都由 240 万个高斯表示。联合模型受到的约束是位置和形状共享，不是数量少一半。
2. **单纯加容量是 9 月已经封口的方向**（`mcgs_sg2x2_wt/docs/2026-09-28-widen-mcgs-summary.md`「已知的坑」）。
3. **已有数据显示加点帮不了这个差距：**
   - T1+FLAIR 容量记录，3.6M 到 7.2M：T1 −0.04、FLAIR +0.03 dB；
   - T1+T2 在 v2 下，T1 从 1.2M 往上一路下降（1.6 / 2.4 / 4.8M：34.91 / 34.57 / 32.24）。

   加到 480 万，最可能是 T1 再降、T2 小涨。tangbing 上 T1 本来就落后或持平，所以达不到目标。

另外，我在报告里用「脑脊液一亮一暗」解释差距，这是推测，没有验证。9 月有记录的机制是上一条第 3 点的点数不对称。

### 4.4 限定

- 一个受试者，一个种子。
- 独立模型的对比内先验权重沿用完整模型的，没有单独调参。
- 真值是全采样 k 空间用同一组 ESPIRiT 线圈图合成的图像（`presampled: false`，与 huangyuwei 相同）。
