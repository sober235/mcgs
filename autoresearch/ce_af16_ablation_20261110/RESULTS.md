## 3. 读法

1. **对比内先验是决定性的。** 去掉幅值 TV、相位 TV、小波后下降 4.9 至 12.4 dB，重建过拟合噪声。高斯表示加共享几何本身不提供足够的正则。
2. **各向异性的作用小而一致。** 六个格子都下降，0.02 至 0.12 dB。CE 和 T1+FLAIR 上约 0.02 至 0.04 dB，T1+T2 上 0.07 至 0.12 dB。都高于重跑噪声，但 CE 和 T1+FLAIR 上的幅度没有实际意义。
3. **联合建模的作用在 ±0.1 dB 内，方向不一致。** T1+FLAIR 上联合更好（去掉后 −0.091 / −0.045 dB）。CE 上独立模型略好（+0.080 / +0.009 dB）。T1+T2 上一正一负（−0.064 / +0.073 dB）；这个任务的完整配方没有跨对比损失，所以这里比较的只是共享几何。六个格子里三个为负、三个为正。
4. 与已有结果的关系：T1+FLAIR 的 −0.091 / −0.045 dB 与 widen 轮次的公平裕量（+0.106 / +0.064 dB）、耦合归因的 M1（+0.148 / +0.042 dB）同号同量级。10 月 2×2 结构消融在开发受试者上得到的 A − B 为 +0.006 / −0.022 dB，那个设计四组都关掉了跨对比损失，所以更小。

## 4. CE：用独立单对比模型核对 9 月的逐层结论

### 4.1 为什么要核对

9 月课题（`Results_20260908/CE_retro_cssense_af16`）的结论是：MC-GS 在病灶层面 201 / 131 / 48 的六个面板上全胜，逐层第一 602 / 604（平扫）和 604 / 604（增强），第二名是 GS-single。课题登记的 GS-single 是把同一个扫描送进联合模型的两个通道（公共边缘先验仍然开着），不是独立的单对比模型。本次消融的「去掉联合建模」训练了真正独立的单对比模型，它在整头 PSNR 上不低于联合模型。所以需要看逐层结论在换成这个模型之后是否还成立。

### 4.2 做法

脚本 `abl_ce_slices.py`（CPU，对课题目录只读）：

- 把消融的体积换到课题评分口径，算法与课题的 `extract_gs_volumes.py` 相同（乘以训练器归一化系数与课题归一化系数之比）。核对：同一算法作用在 9 月联合运行的 npz 上，逐体素复现了登记的 `gs_joint` 体积（最大差 0）；消融运行的零填充体积与 9 月运行逐体素相同（最大差 0）。
- 逐层排名用课题 `find_best_slice.py` 的定义：三个轴向、头部体素不少于 2000 的层、该层的头部 PSNR、十一个方法。用登记的方法先跑一遍，复现了 602 / 604 和 604 / 604。
- 病灶层面取病灶核心不少于 150 像素的层（横断 17、冠状 24、矢状 18，共 59 个），每层的 PSNR / SSIM / NMSE 用 `fig_lesion_plane_prepost.py` 的 `plane_metrics` 算法。3D-DIP 和 3D-INR 用加头部支撑后的重跑，与当前的定稿图一致。

### 4.4 结论

- 9 月「六个面板全胜」和「逐层第一 602 / 604、604 / 604」是相对登记版 GS-single 成立的。换成真正独立的单对比模型后不成立：三个层面 18 项里赢 5 项，59 个病灶层面里没有一个六项全胜，逐层第一降到 143 / 604（平扫）和 317 / 604（增强）。
- 登记版 GS-single 比独立模型低 0.27 / 0.36 dB（课题口径，整头）。两者的命令行有三处不同（核对自各自的评分 json）：登记版在两个相同通道之间仍开着公共边缘先验（`lambda_edge` 0.001，独立模型为 0）；登记版引用 plain 通道，所以增强扫描用的小波权重是 0.12，独立模型用它在联合模型里的 0.10；登记版走联合训练器（两套密度拟合同一个扫描），独立模型走单对比训练器。耦合归因在 T1+FLAIR 上测得公共边缘先验对单对比一侧有害，方向一致。本次没有把这三个因素拆开。
- 联合模型与独立模型在这份数据上是同一水平：平扫上独立模型略好（逐层中位数 −0.069 dB），增强上持平（+0.004 dB）。差值远小于它们对其余方法的领先。
- **仍然成立的部分：** MC-GS 在全部 59 个病灶层面、六项指标上都高于其余九个方法（ZF、CG-SENSE、CS-SENSE、Joint SENSE、L1-SPIRiT、ZS-SSDU、3D-DIP、3D-INR、MC-INR）。这一条带着原有的限定：这里的 ZS-SSDU 是 5 块网络，BART 掩膜上没有按 15 块重跑。
- 对论文主张的含义：在这份 CE 数据上，可以主张「GS 表示加对比内先验优于九个对比方法」，不能主张「联合多对比建模优于独立的单对比 GS」。

### 7.1 tangbing 上调参后的结果（2026-11-14）

**原因。** 用户 2026-11-13 定的标准：完整 MC-GS 在 T1 和 T2 上都要优于三种消融配置，PSNR、SSIM 更高，NMSE 更低，共 18 格；方法定义不变，只允许针对 T1+T2 调参数。上表里「去掉联合建模」一行不达标，所以在 tangbing 上做了调参（`autoresearch/ablation_coupling_tune_20261111/program.md` 第 11 节，R1–R5，21 次训练）。上面的表保留不动。

**规则。** 不改代码，不加损失项，不改数据、掩膜、真值和评分器。每个配置都有的设置，在完整模型和独立模型上同样改，独立模型重跑；完整模型要和所有跑过的独立模型里最好的那个比。只属于联合模型的参数只改完整模型。

**最终配置。** V32，加上：
- T2 小波权重 0.05 → 0.08；
- 高斯旋转学习率 0.0003 → 0.008；
- 高斯尺度学习率 0.002 → 0.004；
- 公共边缘先验 0 → 0.001，门控锐度 `edge_kappa` 10 → 100（这两项只属于联合模型）。

前三项对所有配置同样改。种子 42，4000 步，每个模型 240 万个高斯。

**读法。**
- 三行、两个对比度、PSNR / SSIM / NMSE 共 18 格，完整模型全部更好。HFEN 也是全部更好。
- 最小的余量是对独立 T2 的 PSNR，+0.034 dB。
- 种子 7 复核（完整模型和两个独立模型各重跑一次）：T1 +0.124，T2 +0.031 dB，SSIM、NMSE 同向。同一配置两个种子之间只差 0.001–0.004 dB。
- 相对上表的 V32 完整模型（33.791 / 34.656），最终配置高 0.168 / 0.439 dB；独立模型也从 33.795 / 34.760 升到 33.835 / 35.061。提高主要来自两个学习率，它们对所有配置都有利，对联合模型更有利。

**限定。**
- 一个受试者，参数在它自己的真值评分上调出；种子 7 只检验了随机种子，没有检验别的受试者。
- 只属于联合的两项在独立模型上没有对应物；其余三项独立模型得到了同样的搜索。
- 去掉各向异性、去掉对比内先验两行只跑了种子 42。
- 去掉对比内先验的模型在全体积 SSIM、NMSE、HFEN 上没有同时胜过零填充（原配方下也是这样）。
