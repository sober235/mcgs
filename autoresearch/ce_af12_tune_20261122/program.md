# AF12 平扫 / 增强：MC-GS 参数调优循环（Karpathy autoresearch）

用户，2026-11-22：「Continue to fine-tune the parameters using Karpathy's autoresearch, and further improve the
reconstruction quality of MCGS.」上文是 AF12 平扫 / 增强的最优结果图（`../ce_af12_rerun_20261112/README.md`），
所以调的是这一对数据上的 MC-GS。研究问题、指标和范围是我按上下文定的默认值，用户可以改。

## 设定

- **研究问题：** 在 AF12 平扫 / 增强数据上，调参能否让 MC-GS 的重建质量高于现在记录里的未调参九月配方（P3）。
- **指标（一个数）：** m = 平扫与增强全头 PSNR 的平均值（训练器自带评分 `*_score.json` 的 `head_psnr`）。
  同时记录 SSIM、NMSE、HFEN。
- **基线：** 登记的 AF12 运行（九月训练器快照）在同一评分下为 35.805 / 38.145 dB，m = 36.975。
  （专题换算口径下是 35.913 / 38.256，即 README 表里的数；循环内只用训练器口径比较。）
- **训练器：** 框架消融用的训练器副本（源 54f8a2a，`codex_artifacts/mcgs_framework_ablation_20261110/trainer`），
  因为它有跨对比度引导项，九月快照没有。第一轮是对照（不加任何改动），用来量两个训练器之间的差。
  之后一律与对照比较。
- **不变的东西：** 数据、真值、掩模、线圈图、配置文件 `CE_retro_cssense_af12/configs/ce_retro_af12.yaml`、评分方式。
  真值只用于评分，不进训练。其余十种方法不动。
- **保留规则：** m 比当前保留配置高出 0.02 dB 以上，且两个对比度的 PSNR 都不下降、SSIM 都不下降，才保留。
  （同卡重复运行的波动此前量得约 0.001–0.005 dB。）
- **停止：** 连续 3 轮不保留就停下来问用户；预算先定 12 次训练。
- **每轮一个假设。** 有多张空闲卡时并行跑互不依赖的假设；组合项只在各自单项有结果后再跑，
  例外是把 AF16 已验证的整套保留配置当作一个假设直接迁移。
- **限定：** 一个受试者、一次掩模抽样、种子 42；按真值挑参数（三个扫 λ 的对照方法也是按真值挑的）。
  保留配置最后用种子 7 复核符号。调好后的 MC-GS 若要进记录图，需用户决定，届时用专题口径重新出数和出图。

## 已有结论（不重复试）

- AF16 同一对数据的耦合调参（`../ablation_coupling_tune_20261111/`）：`lambda_edge 0`、边缘 TV 引导 α 0.5、
  相位 TV 引导 α 0.5 依次保留，Full 对独立单对比的差从 −0.080 升到 +0.203 dB；`lambda_dtv 0.01` 使增强一侧变差 0.147 dB。
- AF16 三轴 / add-on 轮：点数 1.2–7.2 M 对 PSNR 只有 ±0.02 dB；延长第二阶段无效；二次 NL 目标刷新变差。
  那几轮用的是另一条训练链（NL 目标），其旋钮不在本循环范围内。
- T1+T2（tangbing）第三阶段保留过 `rotation_lr 0.008`、`scale_lr 0.004`、`edge_kappa 100`，可作为这里的候选。

```sh
/usr/bin/python3 ../gpu-tools/gpu.py run --gpu N -- @python autoresearch/ce_af12_tune_20261122/tune12.py \
    --name <名字> "--ov=<覆盖参数>" "--hyp=<假设>"
```

显卡：与其他会话共用，启动前查两次占用并先打招呼；时间一律用本机时钟。

## 结论（2026-11-23）

最终配置 = 登记配方 P3 + `--lambda_edge 0 --set loss.edge_tv_guide_alpha=0.75 --set loss.ptv_guide_alpha=0.5
--set gaussian.rotation_lr=0.008 --set gaussian.scale_lr=0.004`。种子 42：36.031 / 38.473 dB（对照 35.805 / 38.145）；
种子 7：36.022 / 38.465 dB。全头 SSIM、NMSE、HFEN 在两种对比度上都变好。共 8 次训练（预算 12），另有 1 次在共用卡上主动停掉。
尚未做：用最终配置保存重建体积（`--volumes`）并重画临床验证图；那需要再一次训练和用户的决定（是否替换已登记的最优图）。
