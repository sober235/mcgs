# The scheduler takes the first line without a results_arc/<exp>.log, so order = priority.

# Round 2 (moved to the top 20:25): capacity. p3_n60 (6.0M points, c1 weights) scored T1w 38.791 /
# T2s 34.195 in the primary region against c1's 38.516 / 34.163 at 3.6M: +0.275 dB on T1w for 0.5 GB of
# VRAM (the stage-3 record's "+0.001" was wrong). One cloud carries two contrasts in the joint arm, so
# capacity may help it more than the single arm; the singles at the same capacity decide that.
p4_single_T1w_n60 configs/peds_af12_single_T1w.yaml --lambda_geo 0.03 --set loss.lambda_wav=0.06 --set loss.lambda_wav_plain=0.06 --set loss.lambda_wav_contrast=0.06 --set gaussian.initial_num_points=6000000

p4_single_T2s_n60 configs/peds_af12_single_T2s.yaml --set gaussian.initial_num_points=6000000
#
# Round 1c: who drives the shared geometry. At the end of a c1 run the T2s data term is ~5x the T1w
# one, so the shared cloud is pulled mostly by the noisier contrast. dc_weight_contrast w scales T2s's
# data term; T2s's own regularisers are scaled by the same w, so T2s's internal balance (and, under
# Adam, its own densities) is unchanged and only the geometry split moves.
# (p4_dcw02 moved up to second place at 20:35: the joint arm loses T1w at T1w-only edges)
#
# Round 1b: joint (group) wavelet sparsity, sqrt(w_p^2|Wx_p|^2 + w_c^2|Wx_c|^2) per coefficient (new,
# loss.wav_group). At equal weights the group norm is never above the separate sum, so the x1.4 line
# keeps the overall shrinkage comparable.
p4_gwav configs/peds_af12_T1w_T2s.yaml --set loss.lambda_wav=0.10 --set loss.lambda_wav_plain=0.06 --set loss.lambda_geo_plain=0.03 --set loss.lambda_wav_contrast=0.10 --set loss.lambda_geo_contrast=0.10 --set loss.wav_group=true
#
# Round 1a: T1w-guided smoothing of T2s (plain-guided directional TV). T1w is the high-SNR contrast;
# the guide relaxes T2s's smoothing across T1w edges and enforces it where T1w is flat.
