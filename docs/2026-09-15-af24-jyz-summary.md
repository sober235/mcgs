## 1. 结论

- AF16 三期配方原样不调，放到 T1 恰好 24 倍的掩膜上，MC-GS 在全部对比方法（含 GS-single）中头内 PSNR、SSIM、HFEN 六项全部第一。
- 最强对比臂是 GS-single。MC-GS 对它的余量 **+0.179 / +0.071 dB**（T1 / FLAIR），AF20 是 +0.165 / +0.052。
  四个倍数连起来：T1 +0.150 → +0.148 → +0.165 → +0.179，FLAIR +0.036 → +0.042 → +0.052 → +0.071——FLAIR 上联合相对单臂的增益随加速严格单调上升。
- 最强的非 GS 臂是 T1 的 CS-SENSE 收敛 TV（32.820）和 FLAIR 的 Joint SENSE（32.605），MC-GS 对它们的余量 +0.947 / +0.577（AF20 +0.829 / +0.634）。
- 新加的两个对比臂：L1-SPIRiT（k 空间）31.783 / 31.803，在对比臂里排第六；MC-INR 30.076 / 30.947。两者都不改变顶部名次。
- 加速倍数按用户 09-14 的口径（整平面点数 ÷ 该对比度带数据的采样点数）：T1 **24.00×**、FLAIR **25.51×**。FLAIR 的标签怎么写还有一个待定（第 7 节）。

## 2. 实验设计

唯一变量是掩膜。受试者、k 空间、ESPIRiT 灵敏度图、真值、打分代码都和 AF12/16/20 课题相同（k 空间和灵敏度图是指向 AF12 课题的软链接）。

| 掩膜 | PE 点数 | T1 加速 | FLAIR 加速（整平面口径） |
|---|---|---|---|
| AF12 | 3847 | 11.71× | 12.86× |
| AF16 | 2966 | 15.19× | 16.49× |
| AF20 | 2427 | 18.56× | 19.96× |
| **AF24** | **1877** | **24.00×** | **25.51×** |

- AF24 掩膜是从生成器的抽样池里挑出 T1 正好 24.00× 的一张（1877 点），两个对比度共用；`.mat` 与 `.h5` 不能重新生成（生成器按 `time(0)` 取种），只在课题 `data/` 和本次的数据包里。
- MC-GS 与 GS-single 用 AF16 三期配方，一个参数没动；经典方法的 λ 在 AF24 上重扫，最优点全部在网格内部。
- L1-SPIRiT 用 AF12/16/20 同一套代码和网格（3×3 / 5×5 核 × 六个 λ，150 步），取 5×5 / λ=1e-3；MC-INR 用复现仓库 `mcinr_niessen2025` 在本课题掩膜上跑，经本课题打分器重打分（与复现仓库自己的分数差 1.2e-7）。

## 4. 与 AF20 对比

| | AF20 | AF24 |
|---|---|---|
| MC-GS 减 GS-single（头条余量，T1 / FLAIR） | +0.165 / +0.052 | **+0.179 / +0.071** |
| MC-GS 减最强非 GS 臂 | +0.829 / +0.634 | +0.947 / +0.577 |
| 头内 SSIM，MC-GS 减 GS-single | +0.0032 / +0.0016 | +0.0041 / +0.0023 |
| 头内 HFEN，GS-single 减 MC-GS（正=MC-GS 更好） | +0.0059 / +0.0023 | +0.0080 / +0.0041 |
| 锐度 MC-GS / GS-single | 0.833 / 0.837；0.776 / 0.778 | 0.803 / 0.806；0.738 / 0.741 |

- 耦合项（联合减单臂）在更高加速下继续变大，FLAIR 尤其明显；这是"数据越少、共享几何越值钱"的方向。
- 对非 GS 臂的余量维持在 0.58–0.95 dB，没有随加速变大也没有缩小。

## 5. 掩膜抽样方差（旧口径下的测量）

claude-64 用同规则再抽了 b / c / d 三张 1877 点掩膜，每张只跑 MC-GS 与 L1-ESPIRiT（三个 λ）。MC-GS 减 L1-ESPIRiT：T1 +0.359 ± 0.006、FLAIR +0.397 ± 0.006（AF20 是 +0.459 ± 0.002 / +0.488 ± 0.004），从 AF20 到 AF24 的缩小是抽样标准差的 15–17 倍，是真的。
**但这是 09-15 约定之前设计的实验，测的是对 L1-ESPIRiT 的余量；现在引用的余量（MC-GS 减 GS-single）的抽样方差没有测**——GS-single 没在 b/c/d 上跑。是否补跑见第 8 节。

## 6. L1-SPIRiT 与 MC-INR

- L1-SPIRiT 的四倍数序列：T1 35.017 → 33.788 → 32.882 → 31.783，FLAIR 35.103 → 33.720 → 32.824 → 31.803。AF24 上它在两个对比度都落到 ZS-SSDU 之下（AF12 时 FLAIR 还压过 ZS-SSDU）：加速越高，k 空间自洽先验相对图像域稀疏先验越吃亏。FLAIR 上它的头内 HFEN（0.1804）仍是非 GS 对比臂里最低的。
- MC-INR：30.076 / 30.947，对比臂里第九（T1）/ 第八（FLAIR）；它相对 AF20 的掉幅（-0.893 / -0.719）比多数方法小，和它在 AF12→16→20 上的表现一致。

## 7. 加速倍数口径

- 主口径（用户 09-14）：整个相位编码平面的点数 ÷ 该对比度真正带数据的采样点数，即 BART `pics` 的 `Acc`。AF24 掩膜 1877 点里 FLAIR 有数据的是 1766 点（111 点落在 FLAIR 未采集区），所以 T1 24.00×、FLAIR 25.51×。图标题、表格、本文全部用这个口径。
- 原始 CFL 显示 FLAIR 只采了 45056 线里的 34139 线（椭圆扫描 + ky 0–19 行未采，`figures/t1flair_v3_af24_raw_kspace_support_T1_vs_FLAIR.png`）。若对"FLAIR 原始采集"算，是 19.33×；若按掩膜点数算，两个对比度都是 24.00×。
- **待定（用户）**：A 保持 24.00 / 25.51；B 两个对比度都标 24.00 并加注——选 B 的话 AF12/16/20 要同样改。
