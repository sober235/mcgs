# MC-GS 对全部对比方法拉大余量：公平口径、四档 AF、天花板探针（jiangyizhou T1+FLAIR，2026-09-24 至 09-28）

分支 `widen-mcgs-af12-16-20-24`（工作树 `/data0/congcong/code/GS/mcgs_widen_wt`）。它从 `widen-mcgs-af16-20-24` 延续而来，
祖先是 `coupling-attribution` 81fe792 ← `hparam-sensitivity` ← GitHub 上的 `autoresearch-jyz-af24` 5ea6189。

## 结论

1. 同一套配方下，MC-GS 在 AF 11.71 / 15.19 / 18.56 / 24.00 四档、两个对比度、头内 PSNR 和 SSIM 上，对全部对比方法都是第一，
   包括公平口径的 GS-single。
2. 对 GS-single 的领先只有 0.02 到 0.12 dB。对最强的非 GS 方法领先 0.63 到 1.08 dB。
3. 已发表的余量（+0.148 / +0.042 等）偏高：当时的 GS-single 也带着共同边缘先验，而这个先验会拖累单臂。
4. 天花板探针表明，在这对数据上，任何非学习的跨对比度先验都拿不到 0.3 dB 以上：伙伴对比度全采样也不行，把真实边缘图直接给它也不行。
   原因可以数出来：T1 加权和 FLAIR 是两次测量，对应至少四个组织参数，两者之间没有可用的强度关系，只共享边缘位置，
   而边缘位置 GS-single 靠自己的数据已经重建出来了。

## 配方（四档同一套）

AF16 三期配方（P6 冷启动、3.6M 高斯、边缘 TV λ_geo 0.10 / κ_q 0.85 / w_floor 0.10 / ε 0.04、db4 最细一层小波、4000 步、种子 42），加上：

- 两个臂都加：相位 TV 0.01（原 0.03），T1 小波 0.18（原 0.12）。
- 只加在 MC-GS 上：λ_edge 0.001，R_dtv 0.01，边缘 TV 引导权重 α 0.25（`loss.edge_tv_guide_alpha`），相位 TV 引导权重 α 0.25
  （`loss.ptv_guide_alpha`）。两个引导项是这次新写的，默认关闭，带单元测试。

GS-single = 同样的通道内设置，λ_edge 0，不开任何耦合项；每档取所有单臂运行里最好的那个（规则 A）。
