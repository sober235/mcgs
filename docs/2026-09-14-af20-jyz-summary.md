## 1. 结论

- AF16 三期配方原样不调，放到标称 AF20 掩膜上，MC-GS 在十个对比方法中头内 PSNR、SSIM、HFEN 六项全部第一。
- 对最强对手 L1-ESPIRiT 的余量是 +0.461 / +0.491 dB（T1 / FLAIR），AF16 时是 +0.497 / +0.425。余量守住了，但没有随加速变大。
- 换四张独立抽样的 AF20 掩膜，余量是 T1 +0.459 ± 0.002、FLAIR +0.488 ± 0.004。所以 AF16 到 AF20 的余量变化是真的，不是抽样噪声（前提见第 5 节）。
- T1 锐度低于 L1-ESPIRiT（0.833 < 0.845），四张掩膜都是如此。FLAIR 锐度四张都高于 L1-ESPIRiT。
- 所有结果都是标称 20 倍，实际加速是 T1 18.56×、FLAIR 15.13×（对它自己采到的数据）。没有任何一组是严格的 20 倍（见第 7 节）。

## 2. 实验设计

唯一变量是掩膜。受试者、k 空间、ESPIRiT 灵敏度图、真值、打分代码都和 AF16 课题相同，k 空间和灵敏度图是指向 AF12 课题的软链接。

| 掩膜 | 生成器调用 | PE 点数 | T1 实际加速 | FLAIR 实际加速（对快门内数据） |
|---|---|---|---|---|
| AF12 | `vdPoisMex(256,176,256,176, 3,4,24,0,1)` | 3847 | 11.71× | 9.74× |
| AF16 | `vdPoisMex(256,176,256,176, 4,4,24,0,1)` | 2966 | 15.19× | 12.49× |
| **AF20** | `vdPoisMex(256,176,256,176, 5,4,24,0,1)` | 2427 | 18.56× | 15.13× |

- MC-GS 用 AF16 三期配方，冻结在 `run_af20_mcgs.sh` 一处：P6 冷启动（head 初始化、3-NN 尺度、κ 取自 ZF）、3.6M 点、edge-TV λ_geo 0.10 / κ_q 0.85、kspace_high 2.2、db4 小波只用最细一层（T1 0.12 / FLAIR 0.10）、common-edge 0.001、相位 TV 0.03、4000 步。AF20 运行日志和 AF16 三期运行逐行核对过。
- 经典方法的 λ 在 AF20 上重扫，网格以 AF16 最优点为中心，贴边就扩展。六条 λ 曲线最后都是内部极值。
- ZS-SSDU、3D-DIP、3D-INR 的参数和 AF16 课题日志一致。
- 这个比较对 MC-GS 偏保守：对手的 λ 在 AF20 上重新挑过，MC-GS 的参数一点没动。

## 4. 与 AF16 对比

| | AF16 | AF20 |
|---|---|---|
| 对 L1-ESPIRiT 的余量（T1 / FLAIR） | +0.497 / +0.425 | **+0.461 / +0.491** |
| MC-GS 减 GS-single（耦合项） | +0.148 / +0.042 | +0.165 / +0.052 |
| 头内 SSIM 领先 | +0.0062 / +0.0060 | +0.0083 / +0.0066 |
| 头内 HFEN 领先 | 0.0147 / 0.0089 | 0.0164 / 0.0116 |
| 锐度 T1，MC-GS 对 L1 | 0.855 ≥ 0.849 | 0.833 < 0.845 |
| 锐度 FLAIR，MC-GS 对 L1 | 0.804 ≥ 0.789 | 0.776 ≥ 0.732 |

- 余量基本持平，靠提高加速把差距拉到 1.0 dB 的思路不成立。SSIM 和 HFEN 的领先在两个对比度上都变大了。
- 耦合项在更高加速下价值几乎不变。GS-single 单独就比 L1-ESPIRiT 高 0.30 / 0.44 dB，余量的大头来自高斯表示和它的先验。
- 48 体素放大框（在 AF16 结果上挑的框）里的领先在 AF20 上变小，这是挑选效应。对外应报全体积余量。

## 5. 掩膜抽样方差

vd-Poisson 生成器按 `time(0)` 取随机种子，每次抽出来都不一样，而且 AF16 和 AF20 的掩膜不嵌套（AF20 的 2427 点里只有 698 点在 AF16 掩膜里）。为了判断余量的变化是不是换掩膜带来的，又抽了三张 AF20 掩膜，每张只跑 MC-GS joint 和 L1-ESPIRiT（三个 λ）。

| 抽样 | 点数 | T1 实际加速 | FLAIR 实际加速 | T1 余量 | FLAIR 余量 | T1 锐度门 | FLAIR 锐度门 |
|---|---|---|---|---|---|---|---|
| a（主表所用） | 2427 | 18.56× | 15.13× | +0.461 | +0.491 | 没过 | 过 |
| b | 2410 | 18.70× | 15.24× | +0.456 | +0.492 | 没过 | 过 |
| c | 2400 | 18.77× | 15.25× | +0.461 | +0.487 | 没过 | 过 |
| d | 2415 | 18.66× | 15.19× | +0.458 | +0.483 | 没过 | 过 |
| 均值 ± 标准差 | | | | +0.459 ± 0.002 | +0.488 ± 0.004 | 0/4 | 4/4 |

- 单个方法的绝对 PSNR 随抽样波动更大（标准差按 MC-GS / L1-ESPIRiT 列：T1 0.009 / 0.007，FLAIR 0.040 / 0.040），但 MC-GS 和 L1-ESPIRiT 同涨同跌（相关 +0.97 / +0.99），配对余量稳 4 到 10 倍。
- AF16 到 AF20 的余量变化 T1 -0.038、FLAIR +0.063，是抽样标准差的 16 倍和 15 倍。前提是 AF16 那一张掩膜的抽样波动和 AF20 相当。
- L1-ESPIRiT 的最优 λ 在四张掩膜上都没变（T1 0.001、FLAIR 0.003）。

## 10. 过程中的问题（已修复，别再踩）

- 空卡检测写成 `! nvidia-smi ... | grep -q`，在 `set -o pipefail` 下会把忙卡判成空卡（grep 提前退出，nvidia-smi 收到 SIGPIPE）。结果三张掩膜的 MC-GS 挤到同一张卡，一个显存溢出。已改为先存变量再 grep。
- `echo "[$(date)] rc=$?"` 里 `$(date)` 先执行，把 `$?` 覆盖成 0，崩掉的作业被记成成功。已改为先 `rc=$?`。
- 别的会话的调度器会在卡空出后几十秒内抢走。自己的下一个作业要接同一张卡，就在上一个进程退出时直接交接。
- ZS-SSDU 挨着别人的长作业慢 10 倍（每个 epoch 530 秒对 52 秒），损失逐位相同。起跑前挑没有计算进程的卡。
- MC-GS 先写分数 json，再写约 750 MB 的体积 npz。登记之前要等进程退出，否则 `BadZipFile`。
- 掩膜无法重新生成，四张 `.mat` 只在课题 `data/` 里。不要在那里重跑 `prep_02_mask.m`。
