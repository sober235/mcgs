# 运动研究第三版：T2W 扫描内的非刚体运动（实验方案）

日期：2026-11-25（本机时钟，PST）。状态：**待用户审阅，未开始执行。**
前两版：`autoresearch/motion_adapter_sim_20261113`（第一版）、`autoresearch/motion_mild_adjust_20261121`（第二版，
设置已冻结，代码作为库使用，不改）。新目录：`autoresearch/motion_nonrigid_20261125`；
新分支：`exp/motion-nonrigid-20261125`。

## 1. 要回答的问题

T1W 只是欠采样、没有运动；T2W 采集过程中发生了非刚体运动。在不明显改变 MC-GS 框架的前提下，能否把这种
运动建模并从 T2W 图像里消除？

只处理这一个问题。扫描间错位、扫描内刚体运动、线性回波链顺序都不在本轮范围内。

## 2. 方法：M4，按状态的形变场

- **共享高斯不变。** T1W 一支照旧，作为几何的参照。
- **T2W 的每个运动状态 s 有一个形变场 u_s。** 渲染状态 s 时高斯中心移到 x + u_s(x)，协方差按形变的局部梯度
  修正；参照状态的 u 恒为零。损失只在该状态的回波链采样线上计算（第二版 M3 的通路，`mpatch.make_kloss`）。
- **形变场用粗控制网格。** 沿用第一版 `adapter.MotionAdapter` 的三线性控制网格（现为 5×5×5，幅度上限 3 mm，
  tanh 限幅，去均值），由"全局一个"扩成"每个状态一个"，初值为零，加平滑和 L2 约束。
- **状态从数据里找。** 短暂的动作由第二版 M2 的回波链统计量识别并降权；持续的形变由变化点检测分成状态。
  检测统计量是否对非刚体形变敏感，是探针要回答的第一个问题（第 5 节）。
- **训练分三步。**
  1. 到检测迭代为止：T1W + 被判为干净的 T2W 回波链，建立标准形状（M2 照常工作）。
  2. 检测到新状态后的一段迭代：冻结 T2W 密度和共享几何，只训练新状态的形变场。
  3. 之后一起训练，直到结束。
- **输出。** 在参照状态（u = 0）下渲染 T2W。数据一致性插回只用参照状态的、未降权的采样线（第二版的口径）。
- **无运动时不动。** 没有检测到新状态就不建形变场，模型与 MC-GS + M2 相同。

对 MC-GS 框架的改动：一个按状态的控制网格参数组、一次按状态的渲染。高斯的表示、损失项、致密化都不改。

## 3. 模拟数据

数据、掩膜、种子与第二版相同：hyw 的 T1W + T2W，AF12，种子 42，交错回波链顺序。模拟器是现有的
`simulate.build_custom`，它已支持"每条回波链按幅度叠加一个软组织形变场"；本轮的事件把刚体部分设为零，只留
形变场。

形变场用 `warp.rbf_field` 生成（4 个高斯径向基，3 个在颈部和下颌、1 个在脑内，宽度 30–50 mm）。
正式条件用种子 31，开发条件用种子 47。

| 条件 | 运动 | 形变场峰值 / 脑内上限 | 用途 |
|---|---|---|---|
| C0 | 无 | — | 关卡（沿用第二版数据） |
| Na | 一次短暂形变，位于采集进度 0.40，持续 0.05 | 3 mm / 1.5 mm | 正式 |
| Nc | 一次持续形变，从采集进度 0.60 起 | 3 mm / 1.5 mm | 正式 |
| Nc-s | 同 Nc，幅度减半 | 1.5 mm / 0.75 mm | 正式，小幅度 |
| NcL | Nc 加病灶（第二版的病灶位置与大小） | 3 mm / 1.5 mm | 正式，病灶 |
| DNa | 一次短暂形变，位于 0.55，持续 0.06 | 3 mm / 1.5 mm | 只用于选设置 |
| DNc | 一次持续形变，从 0.45 起 | 3 mm / 1.5 mm | 只用于选设置 |

脑内 1.5 mm 的形变大于生理上常见的脑组织形变，是有意加大的压力测试；Nc-s 给出较小幅度下的表现。

## 4. 对照组

| 组 | 内容 |
|---|---|
| B0 | MC-GS 不改 |
| B2 | 只按回波链降权（第二版冻结设置） |
| B123 | 第二版全部改动，状态位姿是刚体（冻结设置）：看刚体模型遇到非刚体运动时的表现 |
| Ow | 真值权重：降权的上限 |
| N4 | 本轮方法：M2 + 检测状态 + 按状态形变场 |
| On | 真值状态 + 把真值形变场拟合到控制网格上并固定：形变场模型的上限 |

## 5. 步骤与停止规则

**步骤 0：探针（只用 CPU，不训练）。** 生成 DNa、DNc 的数据，用第二版 C0 / B0 的 T2W 重建作为模型，计算：
- (a) 被形变污染的回波链能否被 M2 的统计量分开：DNa 上 AUC ≥ 0.95。
- (b) 持续形变的边界能否找到：DNc 上某个按回波链的统计量给出的变化点与真值相差不超过 2 条回波链。
  候选统计量：第二版的线性化位移、残差能量比，以及按空间分块的线性化位移。
- (c) 5×5×5 控制网格能否表示真值形变场：最小二乘拟合后脑内平均残差 ≤ 0.2 mm；不够就试 7×7×7、9×9×9。

(a)(b) 任一项不过，**停下并报告**，不进入训练。(c) 决定控制网格的尺寸。

**步骤 1：实现与测试。** `MotionAdapter` 增加按状态的控制网格；`mpatch` 增加三步训练和 M4 的设置项；真值组 On；
评估里增加形变场误差。小模型上的单元测试，零运动下与 B2 逐位一致的测试。

**步骤 2：开发（只在 DNa、DNc 上，至多 8 次训练）。** 选检测统计量的阈值、第 2 步的迭代数、形变场学习率和
约束强度。选定后写入 `settings_frozen.json`，此后不再改。8 次用完仍不能在 DNc 上收回一半损失，**停下并报告
否定结果**，不跑正式矩阵。

**步骤 3：零运动关卡（1 次训练）。** C0 / N4，见判据 N1。不过就不跑正式矩阵。

**步骤 4：正式矩阵（16 次训练）。** Na、Nc 各 6 组（12 次），Nc-s 的 B0、N4（2 次），NcL 的 B0、N4（2 次）。

**步骤 5：评估、图、`RESULTS.md`（中文）、一次整体审阅、一次修正。**

训练次数上限：开发 8 + 关卡 1 + 正式 16 = 25 次，每次约 75 分钟（本机计时，第二版的经验值），单卡约 31 小时。
占用 1 张卡，计入项目 4 张卡的上限；别的会话在等卡时不多占。

## 6. 判据（执行前固定）

"收回比例" = (该组 T2 − B0 的 T2) / (C0 / B0 的 T2 − B0 的 T2)，全脑 PSNR，与第二版相同。

| 判据 | 内容 | 界限 |
|---|---|---|
| N1 无运动不变差 | C0 / N4 相对 C0 / B0 的 ΔT1、ΔT2；是否多开状态 | 都 ≥ −0.05 dB；状态数为 1 |
| N2 收回 | Na、Nc 上 N4 的收回比例（B0 的损失 ≥ 0.1 dB 时才判） | 都 ≥ 0.5 |
| N3 形变场 | Nc 上估计的状态形变场与真值的脑内平均误差 | ≤ 0.3 mm，且 ≤ 真值脑内平均位移的一半 |
| N4 病灶 | NcL 上各病灶的对比度恢复，N4 相对 B0 的最差差值 | ≥ −0.05 |
| N5 T1W | 所有正式条件上 N4 的 ΔT1（相对同条件的 B0） | ≥ −0.05 dB |

只报告、不判定：N4 与 B123、B2、Ow、On 的差；Nc-s 上的收回比例；被错误降权的干净回波链比例。

## 7. 已知的风险

1. **检测不到。** 第二版的变化点统计量是为整体位移设计的，局部形变可能不显著。探针 (b) 先回答。
2. **密度吸收形变。** 第一版的教训：T2W 密度自由时位姿学不动。本轮用第 2 步的冻结来防，是否足够由开发轮回答。
3. **发明运动。** 第一版里目标函数偏好凭空的分段运动。本轮只在检测到状态后才建形变场，并由 N1 把关。
4. **只在 T2W 出现的结构。** 病灶不受 T1W 约束，可能被形变场挪动。N4 把关。
5. **一条回波链内部的运动没有建模**；回波链之间逐条变化的连续运动（呼吸样）本轮也不做，留作后续
   （每条回波链一个幅度的低秩模型）。
6. **结论的范围。** 一名受试者、一个加速倍数、一个种子、模拟运动；不是真实运动数据上的验证。
