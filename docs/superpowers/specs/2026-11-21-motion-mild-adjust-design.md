# MC-GS 应对轻微运动：三处小改动（设计）

写于 2026-11-21 07:15 PST（本机时钟）。这是第二版方案；第一版见
`2026-11-13-motion-adapter-sim-design.md`，它的结果见
`autoresearch/motion_adapter_sim_20261113/RESULTS.md`。

## 0. 一段话

第一版让适配器的全部参数都通过 k 空间数据一致性去学，结果四条判据都没有通过。失败的位置在目标函数：
扫描间位姿在数据一致性里没有信号；扫描内的分段位姿在欠采样下不可辨认，目标函数的最小值偏向造出来的运动。
第二版不换框架，只做三处小改动：**(M1)** 扫描间变换由配准给出，不靠数据一致性去学；
**(M2)** T2 的数据一致性按回波链加可靠性权重，把偶发运动期间采到的数据降权；
**(M3)** 检测到「动了以后没回来」时，给之后的数据一个单独的位姿。
MC-GS 的配方、共享几何、各对比度的密度、先验和评分器都不改。

## 1. 意图

用户原话：

- 2026-11-21："What I'm trying to do is to handle the situation where there is a slight non-rigid movement
  (this refers to within another contrast scan) from different contrast acquisition processes."
- "The solution you provided should not significantly deviate from the main framework of the MCGS.
  Instead, implement minor adjustments to develop the model for the above two movements."
- 问到扫描内运动具体指什么时："brain, Accidentally, Just go and apply the mild (mild motion artifact) yourself."

我的理解（已向用户复述过前两条）：

1. **扫描间：** 不同对比度先后采集，后一个对比度（T2W）整体相对 T1 有位移，含轻微非刚体成分。
2. **扫描内：** T2W 采集过程中大脑偶尔动一下，幅度轻微，造成轻度运动伪影。
3. 方案必须是主框架上的小改动。运动的具体幅度和形式由我定。

规模：这是一个项目（新的仿真条件、三处代码改动、一组实验），需要实施计划。

## 2. 第一版失败在哪里（本设计的依据）

| 失败 | 环节 | 原因 | 证据 |
|---|---|---|---|
| 扫描间位姿学不动 | 目标函数 | T2 的密度独立于 T1，并且在未变换的高斯位置上从 T2 的零填充图取初值（`joint_trainer.py`：`d_c = zf_c[ix, iy, iz] * 0.1`）。位姿为 0 时数据项已经最小 | 位姿梯度的符号一致性 0.00–0.05 |
| 分段位姿造出运动 | 目标函数 + 采集顺序的假设 | 8 段是 8 个互不重叠的 kz 频带，各段没有共同内容，位姿不可辨认 | r4：损失更低，图像差 3.18 dB |
| 真值位姿只收回 36–52 % | 前向模型 | 每段一个平均位姿，表示不了段内变化 | O 组 |
| 发现得晚 | 验证流程 | 冻结前没有查带分段位姿的组在零运动下的表现 | 台账 |

另外两个事实：

- 扫描间错位对图像质量的影响只有 0.02–0.06 dB；位姿完全正确也只多 0.03–0.05 dB。
- 只读探针 `probe_reginit.py`：对 AF12 的零填充 T1、T2 做 NGF 刚体配准，差分配准误差 0.04 mm（D1）、0.08 mm（D2）。

## 3. 目标、非目标、反目标

**目标**

- G1 扫描间：T1 与 T2 对齐（刚体部分脑内平均配准误差 ≤ 0.2 mm），图像质量不下降。
- G2 扫描内偶发轻微运动：在「每条回波链都跨越整个 k 空间」的采集顺序下，收回 T2 损失的一半以上。
- G3 没有运动时，每一个改动都不降低质量、不报出运动。
- G4 改动限于：训练前的一步配准、现有数据项上的一组权重、现有适配器的复用。V32G 配方不动。

**非目标**

- 连续的大幅运动；逐回波链的非刚体建模；T1 采集中的运动；其他受试者；胜过独立单对比度模型；真实（非仿真）运动数据。
- 在 kz 线性顺序下收回损失：只如实报告，不设通过线（第 5 节）。

**反目标**（出现任何一条就算失败）

- 没有运动时造出运动，或者把干净的数据降权而使质量下降。
- 在测试条件上调参。
- 估计运动时用到真值图像、真值运动或 ROI。
- 改动冻结的评分器、掩膜、对比方法。

## 4. 约束

- 项目规则不变：GPU 只经 `gpu.py run --gpu ID`，一卡一任务，启动前隔约 75 秒查两次空卡；时间只用本机时钟，
  不读服务器上的任何时间；真值和 ROI 不进训练。
- 代码以运行时补丁的方式作用在私有训练器副本上（沿用第一版的 `patch.py` 做法），不改训练器包。
- 仍在分支 `exp/motion-adapter-sim-20261113`、同一工作树。新目录 `autoresearch/motion_mild_adjust_20261121/`，
  服务器新根目录 `codex_artifacts/mcgs_motion_mild_adjust_20261121`。第一版的文件只做追加式修改，原有测试必须仍然通过。
- 数据仍是 huangyuwei 的 T1 + T2W，AF12 为主。

## 5. 一个必须说明的假设：回波链的采集顺序（我定的）

真实的采集顺序不知道：数据是厂商补全后的全 k 空间，协议里的排序模式是一个含义未知的枚举值（40）。
第一版假设 kz 线性，这是对「从数据里辨认运动」最不利的情况。3D 快速自旋回波序列通常让每条回波链跨过 k 空间的大范围，
所以第二版用两种顺序：

- **交错顺序（主）：** 椭圆支撑内的相位编码点按光栅顺序编号，第 i 个点属于第 `i mod 链数` 条回波链，
  回波链按编号先后采集。每条链的 320 个点散布在整个 k 空间。
- **kz 线性（对照）：** 与第一版相同。预期在这种顺序下三处改动都拿不回损失，但也不应造成损害。

结论只对所用的顺序成立，两种都报告。**如果用户能从厂商或序列文档查到真实顺序，应以真实顺序为准。**

| 方案 | 做法 | 取舍 |
|---|---|---|
| A 沿用第一版再调参 | 所有运动参数仍通过数据一致性学习 | 已有证据表明目标函数没有信号或最小值不对；不采用 |

用户把「怎么做」交给了我，我选 B。

## 7. 方法

### 7.1 M1：扫描间变换由配准给出

- **训练前（CPU，只用实测的欠采样数据）：** 对零填充的 T1 和 T2 做 NGF 刚体配准，得到 (θ, t)。
  把 `probe_reginit.py` 里已有的做法整理成模块。
- **初始化：** 适配器的刚体参数取这个结果。T2 的密度初值、以及任何由 T2 数据导出的空间图，
  都在变换后的高斯位置上取值，使模型一开始就是对齐的。
- **非刚体成分（粗网格 5×5×5）：** 初值为 0。训练前期加一个跨对比度的对齐项：
  把 T1 的密度按当前变换渲染到 T2 坐标系，与 T2 的渲染比较边缘方向（NGF）。梯度只传给适配器，
  两幅图对高斯参数都不传梯度。到规定的迭代数后适配器冻结。
- **退路：** 如果开发条件上非刚体细化不比「只用刚体」好，就关掉它，只保留刚体，并如实写明。
- 适配器的结构（6 个刚体参数 + 粗网格，作用在共享高斯上）与第一版相同。

### 7.2 M2：T2 数据一致性按回波链加权

- T2 的数据项由 Σ_n r_n 改为 Σ_n w_n · r_n。r_n 是第 n 条回波链上各点的残差能量，归一化仍用训练器固定的分母；
  w_n ∈ [0, 1]，不参与求导，没有新增的可学习参数。
- **权重怎么来：** 预热之后每隔若干步重算一次。先按 |k| 分壳层取全部采样点残差的中位数，得到「该位置的正常残差」；
  每条链的残差除以它所含各点的正常残差之和，得到 ρ_n；再对全部回波链取稳健的 z 分数（中位数和 MAD）。
  z ≤ z0 时 w = 1，z0 到 z1 之间线性降到 0。被降权的总量设上限。
- **为什么这次残差能显出异常：** 交错顺序下，一条被污染的链上的点在 k 空间里被别的链的点包围；
  多线圈之间的耦合和先验不允许一幅自洽的图像同时拟合这少数错位的点。kz 线性下错位的是一整个频带，
  可以被图像吸收，权重预期保持为 1。
- **评分：** 带权重的组做硬数据一致性时只插回 w ≥ 0.5 的采样线；同时报告插回全部采样线和原始渲染两种口径。

### 7.3 M3：动了以后没回来

- 如果被降权的回波链在时间上连成一段，并且一直持续到扫描结束（或两次变化点之间），长度超过规定比例，
  就把这一段定为第二个状态：恢复它们的权重，给它一个刚体位姿，用现有的分段机制渲染。状态数不超过 3。
- 位姿初值：把两个状态的数据各自零填充重建，做同对比度的刚体配准；之后用小学习率通过数据项细化。
- **与第一版分段的区别：** 状态的边界来自检测到的时间点，不是固定的 8 等分；交错顺序下每个状态都覆盖整个 k 空间，
  两个状态有共同内容，位姿可以辨认。
- 含有 k 空间中心那条回波链的状态是参考状态，位姿固定为 0。
- 没有检测到这样的一段时，M3 不起作用。

### 7.4 大脑的运动按刚体处理（我定的）

颅内的大脑随头一起动，是刚体；非刚体的部分在颈部、下颌和头皮。M3 的状态位姿是刚体的，
软组织的非刚体残差由 M2 的权重吸收，不单独建模。

## 8. 仿真

沿用第一版的仿真器（图像域加性差分，线圈灵敏度固定），加两样：交错顺序；偶发事件类型。幅度是我定的，都属于轻微。

| 代号 | 内容 |
|---|---|
| C0 | 原始数据，无外加运动 |
| E2 | 只有扫描间：刚体（点头 1.5° 级）+ 非刚体（脑内 ≤ 0.8 mm）。沿用第一版的数据 |
| Ta | 一次短暂的动作：约 40 % 处点头 1.0° + 0.5 mm，持续约 5 % 的回波链，然后回到原位 |
| Tb | 两次短暂的动作（方向不同，0.6–1.0°，各约 4 % 的回波链），第二次之后停在偏离 0.05° / 0.1 mm 的位置（低于「受污染」的界线） |
| Tc | 动了以后没回来：60 % 处点头 1.0° + 0.5 mm 并保持。kz 线性下它就是第一版的 E4a |
| E2+Tb | 扫描间与扫描内同时存在 |
| DTa、DTc | 开发条件，时间点、方向、幅度与测试条件不同，只用来定设置 |

动作期间在刚体之外叠加一个软组织的非刚体位移场（脑内 ≤ 0.5 mm，颈部和下颌更大）。
真值图像是参考位姿下的图像，参考位姿取采到 k 空间中心的那条回波链的位姿，与第一版相同。
「受污染的回波链」定义为：该链的位姿相对参考位姿在脑内的平均位移超过 0.2 mm。
Tb 上另做一份带病灶的数据（沿用第一版的病灶），检查降权不会抹掉病灶。

## 10. 执行顺序（吸取第一版的教训）

1. **先做可行性验证，再做完整实现。** 实现交错顺序和两个开发条件，只跑 3 次训练：DTa 上的 B0、Ow，C0 上的 B0。
   离线算每条回波链的 z 分数。**两个都满足才继续：** 受污染的回波链能被分开（AUC ≥ 0.95）；Ow 收回一半以上的损失。
   否则停下来，把结果交给用户。
2. 实现 M1、M2、M3，每一处都有单元测试。
3. **每个组都先过 C0 的零运动关卡，再冻结设置。** 设置只在 DTa、DTc、C0 上定，调参训练不超过 10 次。
4. 测试条件的正式运行，先跑上限组（Ow、Op）。
5. 评估、出图、结果文件。

## 11. 判据（阈值我定的，不达标如实报告）

- **S1 零运动（C0，两种顺序）：** 每个组相对 B0 的 T1、T2 头部 PSNR 差 ≥ −0.05 dB；至少 99 % 的回波链 w = 1；不产生第二个状态。
- **S2 扫描间（E2）：** 刚体部分的差分配准误差脑内平均 ≤ 0.2 mm，含非刚体时 ≤ 0.3 mm；
  归一化 Δ：T2 ≥ −0.1 dB，T1 ≥ −0.05 dB。
- **S3 扫描内（交错顺序，Ta、Tb、Tc、E2+Tb）：** 完整的组收回 B0 相对 C0 的 T2 损失的一半以上；
  受污染的回波链至少 90 % 被降权到 0.5 以下，干净的回波链被降权到 0.5 以下的不超过 2 %；Tc 的状态位姿误差 ≤ 0.3° / 0.3 mm。
  如果某个条件下 B0 的损失本身小于 0.1 dB，说明问题在该幅度下不显著，如实写明，不计入通过与否。
- **S4 病灶（Tb）：** 对比度恢复不低于同条件 B0 减 0.05；无串扰。
- **kz 线性：** 只报告。预期没有收益；相对 B0 不应低于 −0.05 dB。

## 12. 算力

- 可行性验证 3 次；调参不超过 10 次；正式运行约 40 次（AF12）。M2 不增加渲染次数，M3 每次迭代多 1–2 次渲染，
  每次训练约 1–2 小时（按第一版的本机墙钟估计）。合计约 60–80 GPU 小时。
- AF16 子集是可选项。
