## 目标与非目标

- **目标：** 6 次扫描 × 4 个加速倍数（标称 AF12 / 16 / 20 / 24，净 11.71 / 15.19 / 18.56 / 24.00×）× 11 个方法，共 24 个格子，每格 T1 和 FLAIR 两个对比度。
- **目标：** 一份逐病例结果表和一份统计汇总，口径与记录相同（头部掩膜内的 PSNR / SSIM / NMSE）。
- **非目标：** 不在测试病例上调任何参数，不重画记录图，不改 jiangyizhou 的任何结果，不跑独立版 GS-single 和 widen 配方。
- **会让这件事失败的做法：** 用测试病例的真值挑 λ、挑早停点、挑层面或挑掩膜；只报告 MC-GS 赢的病例；悄悄校正偏移。

## 冻结的设置（全部取自 jiangyizhou 的登记运行，测试病例上不改）

- **掩膜：** 四个加速倍数各用 jiangyizhou 课题里的那一张（`mask_af{12,16,20,24}_3d.h5`），两个对比度共用。运行前核对 sha256。
- **线圈灵敏度：** 每次扫描自己的 ESPIRiT 图，固定做法 `ecalib -t 0.001 -c 0.0 -r 24 -m 1`。vol1 和 vol4 已有，直接用；其余 4 次扫描新算。
- **MC-GS：** AF12 用 P14，AF16 / 20 / 24 用 AF16 第三期配方（p3）。参数从 jiangyizhou 登记运行的 `argv` 读出后原样重放，种子 42，360 万个高斯，4000 次迭代。
- **GS-single：** 同一 `argv`，T1 和 FLAIR 各跑一次。
- **代码：** 服务器工作树 `mcgs_sg2x2_wt`（54f8a2a）的逐文件核对副本。它在 AF12 上重放 jiangyizhou 的联合模型得 37.015 / 36.359，与登记值相差不到 0.001 dB。
- **对比方法的 λ（jiangyizhou 上选出的值）：**

| 方法 | AF12 T1 / FLAIR | AF16 | AF20 | AF24 |
|---|---|---|---|---|
| CS-SENSE（200 次外迭代） | 0.0007 / 0.0007 | 0.0007 / 0.0005 | 0.0007 / 0.0005 | 0.0007 / 0.0005 |
| Joint SENSE（200 次外迭代） | 0.001 | T1 取 0.001 的运行，FLAIR 取 0.0007 的运行 | 同 AF16 | 同 AF16 |
| L1-SPIRiT（核 5，150 次迭代） | 0.002 / 0.001 | 0.001 / 0.001 | 0.001 / 0.001 | 0.001 / 0.001 |

- **其余方法：** CG-SENSE 和 ZF 用默认设置；ZS-SSDU 100 轮、5 个残差块，按自监督验证损失早停；3D-DIP 5000 次、学习率 3e-3；3D-INR 1500 次；这三个的选点都只用留出的 k 空间点，不用真值。MC-INR 用论文配置，每层面 200 步。
- **评分：** 各课题共用的 `t1t2_common.Pair.score`；真值由全采样 k 空间经该扫描自己的灵敏度图合成，按 P99.9 归一化。

## 偏移的处理（我的决定，用户可改）

三次有偏移的扫描按采集到的样子跑，不做校正。稳健性应包含不完美的病例；校正要用到全采样数据，前瞻采集时做不到。
统计里把 6 次扫描分成对齐组（vol1、vol2、vol4）和偏移组（vol5、vol6、vol7）分别列出。
如果 MC-GS 在偏移组明显变差，再向用户提议做一次整数体素校正的敏感性分析，不自行启动。

## 运行方式

- **输出位置：** 服务器 `/data0/congcong/code/GS/3DGS/outputs/codex_artifacts/mcgs_t1flair_af_testset_20261121/`。不写进 `Results_20260908`，不覆盖任何已有文件。
- **课题副本：** 每个（扫描，加速倍数）一个目录，脚本从 jiangyizhou 同一加速倍数的课题克隆，只替换课题路径；k 空间、灵敏度图、掩膜用符号链接。
- **启动：** 仓库里的一个运行脚本（`autoresearch/t1flair_af_testset_20261121/`），全部通过 `gpu.py run --gpu ID` 启动，每张卡一个作业。启动前按规则查两次空卡，间隔约 75 秒。已认领的行会被跳过，可以断点续跑。
- **顺序：** 先数据准备（CPU），再按扫描 vol1、vol2、vol4、vol5、vol6、vol7 推进；每次扫描内先 MC-GS 和 GS-single，再经典方法，最后学习类方法。
- **核对：** 正式运行前，用同一套克隆脚本在 jiangyizhou 的 AF20 上重算一个便宜的经典方法（CG-SENSE），必须与登记值一致（差小于 0.005 dB），证明克隆没有改变口径。
- **时间规则：** 不读取、不记录服务器上的任何时间；耗时按本机时钟量。

## 统计

- **逐病例表：** 每次扫描 × 加速倍数 × 对比度 × 方法的头部 PSNR / SSIM / NMSE；每列 MC-GS 的名次；MC-GS 第一的格数。
- **病例间：** MC-GS 减 GS-single、MC-GS 减该格最强非 GS 方法的差值，给均值、标准差、最小值、符号一致的病例数；按 6 次扫描和按 4 个人（重复扫描先取平均）各算一遍。
- **病例内：** 逐层面配对 Wilcoxon 检验，层面选取规则与现有概览图相同。
- **必须写明的限制：** 只有 4 个人。以人为单位的 Wilcoxon 检验即使全胜，双侧 p 最小为 0.125；以 6 次扫描为单位最小为 0.031，但其中两次是重复扫描，不独立。病例间结论写成"几个里几个一致"，层面级检验注明层面之间不独立。一个种子。ZS-SSDU 是 5 个残差块。GS-single 是登记版。
- **图：** 一张汇总图（每个加速倍数，各病例 MC-GS 相对两个对照的差值），PNG 存在实验目录的 git 忽略子目录里。
