## 1. 论文主张与贡献

### 1.1 主张(一句话)

> 多对比度 MRI 重建中的"共享解剖"不是免费的:它用对比度特异保真度换取全局保真度。CRISP-MR 用未参与拟合的真实 k 空间,逐个局部结构地判定共享是否被测量证据支持。

前半句是**诊断(危害)**,后半句是**方法(修复)**。诊断不依赖本方法胜过任何人,因此它是论文地基;方法是增量。这一结构使论文对 G2(§7)的结果稳健。

### 1.2 贡献排序(投稿呈现顺序)

1. **共享代价的量化审计** —— 在物理一致的注入实验上,证明强制共享类方法(all-shared MC-GS / SGTV / joint-INR / PnP-CoSMo)对对比度特异信号存在可测量的压制与泄漏,并给出无需 GT 的测量侧检测量。**主结果。**
2. **CF 预测式结构路由(CRISP-MR)** —— 用交叉拟合的保留 k 空间决定 shared / private / absent。其收益必须相对 all-shared **与** independent 两端同时成立。
3. **公平基线基准** —— 充分调参的 CS-SENSE(TV / wavelet)、LLR、单对比 3DGSMR、joint-INR,在同一算子、CSM、DC、口径下对照。

### 1.3 明确不主张(写入论文正文)

- 不主张 3D 高斯表示是新的(3DGSMR 已发表于 IEEE TMI,arXiv:2502.06510);高斯只是一种 atom,**voxel-grid CRISP 是必做对照**。
- 不主张 edge-TV 有效;它作为**已记录的负结果消融**出现,附预注册判据与实测表。
- 不主张胜过有训练的展开网络;训练/免训练分两栏报告,不混排。
- 在 CE 队列(§4.7)落实前,不主张临床病灶安全性,只主张"可控注入下的对比度特异信号保持"。

### 1.4 范围裁剪(相对 v2)

| v2 内容 | 处置 | 理由 |
|---|---|---|
| `Sep`(separate-private)状态 | **删**,只留 shared / private / absent | 第四态使状态空间与复杂度编码翻倍,收益无证据 |
| split / merge | **删**,只留 birth + prune | 动态操作越多,选择偏差越难控;birth+prune 足以证明机制 |
| M > 2 | **删**,锁定 M = 2 | 现有成对数据只有 T1+FLAIR 与 pre/post 两类 |
| 命题 1–3 完整理论 | **降级**为附录中的单一可辨识性命题 | 现有假设下能证的有限,写成定理会重蹈过度声明 |
| 频率 continuation | 保留为**实现细节**,非创新点 | 它替代的是被否定的固定频率权重,属修复而非贡献 |
| 576k warm-start 云 | **删** | 单例 checkpoint 无法跨受试者迁移,且其自身扰动(0.077 dB)大于待裁决效应 |

## 2. 方法核心

### 2.1 模型(M = 2,三态)

$$x_m=\Phi^S(\eta^S)\,a_m^S+\Phi_m^P(\eta_m^P)\,a_m^P,\qquad z_j\in\{\varnothing,\;S,\;P_m\}$$

**共享的是几何 $\eta$,幅值 $a_m$ 永远逐对比度独立。** 论文须显式说明这一点。

### 2.2 闭式预测增量(可行性核心)

v2 的字面实现要求每候选 × 每状态 × 每 fold 重新拟合(约 $10^4$ 次拟合 × 约 1 h/次),**不可执行**。本设计改为局部 Gauss–Newton 闭式量,不重拟合:

训练 fold 上一步 GN 更新
$$\Delta\theta_j=\big(J_{\Theta}^{H}WJ_{\Theta}+\lambda I\big)^{-1}J_{\Theta}^{H}W\,r_{\Theta}$$

保留 fold 上的预测负对数似然变化
$$\Delta\mathcal L^{(k)}_{\text{pred}}=\frac{1}{2\hat\sigma^{2}}\Big(-2\,\mathrm{Re}\big\langle r_{\Lambda},J_{\Lambda}\Delta\theta_j\big\rangle+\big\|J_{\Lambda}\Delta\theta_j\big\|^{2}\Big)$$

第一项为"解释掉的保留残差",第二项为"引入保留集的能量";过拟合候选第一项小、第二项大,自动被罚。primitive 紧支撑 ⇒ $J$ 仅覆盖局部体素 × 全线圈,单候选毫秒级。

复杂度项 $\frac{d_{\text{eff}}}{2}\log N_{\text{fit}}$,$d_{\text{eff}}=\mathrm{rank}_\tau(J^{H}WJ)$(高斯参数冗余,不得用参数个数)。

**接纳条件(全部满足):** ① 相对 absent 总增量为负;② ≥ $K-1$ 个 fold 方向一致;③ 超过 null-candidate bootstrap 阈值(**≥ 200 次抽样**,在纯噪声残差上校准);④ primitive 级 FDR 受控(**q = 0.05**,Benjamini–Hochberg)。$K=3$。以上三个数值先于实验固定,只可在 development 上调整并记录。

### 2.3 Fisher 门 = 廉价筛选

Fisher/GN 预条件一致性 $C_{m\ell,j}$ **仅用于把可行状态集从 3 裁到 1–2**,以省常数倍开销;最终状态一律由 §2.2 决定。理由:它依赖局部线性化与 $\lambda_H$ 选取,作判据不够硬,作筛子足够。

### 2.4 循环(birth + prune)

```
每个 structural round:
  1. 在 Θ^(-k) 上算 coil 归一化伴随残差 → 候选峰
  2. Fisher 门筛出可行状态
  3. 每候选 × 每可行状态:闭式 ΔL_pred(K folds)+ 复杂度
  4. 按 FDR 控制批量接纳
  5. 在全部 Ω 上 refit 已接纳结构(唯一的真优化步)
  6. prune:删除后 CF-PMDL 不升者
  停止:连续两轮无显著改善(不得由 GT 指标决定)
```

### 2.5 预注册预测:审计判别力依赖采样设计

- **同掩膜**:两对比度保留位置相同,共享状态无法"借"到新信息,只能靠**复杂度更低**取胜 ⇒ 简约性论证,预测项无优势。
- **互补掩膜**:对比度 1 采到的位置正是对比度 2 未采的 ⇒ 预测项出现实质增益,信息借用论证。

**预注册预测:G2 在同掩膜下大概率给出"共享≈无益",这不构成对 CRISP 的证伪,只说明同掩膜是错误设定;判决在互补掩膜栏。** 本预测先于实验记录于此。

## 3. 数据与冻结实验协议

### 3.1 队列与划分

| 项 | 决定 |
|---|---|
| 主队列 | 16 例配对 3D T1W+FLAIR(已核实),矩阵尺寸混合(220 / 264) |
| 划分 | **5 development / 11 locked test** |
| 划分规则 | ① huangyuwei **先行指定**为 development(已承受约 62 次调参运行,已污染,放入 test 会直接毁掉 test 的无偏性);② 其余 4 个 development 名额,在剩下 15 例中按 `SHA-256(subject_key)` 十六进制升序取前 4。规则先于任何实验固定并写入代码,**不得看结果后调整** |
| 临床副队列 | CE pair,n = 1 患者,单独轨道(§4.7) |

### 3.2 去标识与伦理

`S001…S016` 映射表存于**仓库之外**的单一私有文件;仓库内 config 只出现 token,启用现有但从未使用的 `paired_gs/data/private_paths.py` 接缝;清理全部含姓名的路径、文件名与日志。论文需 IRB/伦理声明、知情同意或豁免说明、数据共享限制、去标识流程。

**伦理覆盖不得假设。** 二次分析与聚合结果发表是否在原审批范围内,须由用户确认;这是唯一的外部硬依赖,未确认前不得启动涉及 16 例的任何工作。

### 3.3 前向模型要素(逐例重建,弃用现有文件)

- **CSM**:逐例重跑 `bart ecalib -t 0.001 -c 0.0 -r 24 -m 1`,ACS 区域、BART 版本、完整命令写入 config;**不使用 `.h5` 自带的 `csm`**(来源不可考)。
- **mask**:按每例自身矩阵尺寸程序化生成 vd-Poisson;**DC 对齐由代码从数据能量峰计算并记录偏移量**,不手工 roll。
- **每例 3 个 mask realization**(不同种子,同密度剖面)。
- **两种采样条件**:
  - *same-mask*:两对比度共用同一图案(现状,对照组);
  - *complementary-mask*:两图案密度剖面相同、**每对比度自身采样预算不变**(只改重叠度,不改加速倍数)。构造方式:先生成对比度 1 的 vd-Poisson 图案;生成对比度 2 时对已被对比度 1 采到的位置施加抑制权重。**ACS 区域两者必须都采**(CSM 估计与 DC 都需要),互补性只施加于非 ACS 区域。目标非 ACS 重叠率 ≤ 10 %,**实际重叠率逐例记录并在论文中报告**。
- **AF**:闸门阶段仅 AF = 12;通过后扩 {6, 8, 10}。

### 3.4 G2 预注册判据

- **主要终点**:coil 域未采样 k 误差 $E_{\text{unobs}}$,逐对比度 / 逐例 / 逐 realization。
- **共享增益** $\Delta=E_{\text{unobs}}(\text{independent})-E_{\text{unobs}}(\text{all-shared})$,同表示、同容量、同迭代预算。
- **判定"共享有空间"须同时满足(仅在 complementary-mask 条件下):**
  1. 5 例 development **全部同号**(符号检验 p = 1/32);
  2. 相对增益中位数 **≥ 2 %**;
  3. 该增益 **>** 同例内 3 个 realization 的散布。
- **次要终点**:脑内 PSNR / SSIM / NMSE,仅报告,不参与判定。
- same-mask 结果仅用于检验 §2.5 的预注册预测,不参与 go/no-go。

### 3.5 统计

层级结构 subject → mask realization → initialization;**不把不同 mask / 初始化当独立样本**。主分析用逐例配对差 + Wilcoxon 符号秩;报告逐例散点而非仅均值。

### 3.6 冻结纪律

- 一切超参、阈值、频率日程、候选预算、bootstrap/FDR 校准**只在 development 上确定**;
- test **只跑一次**,结果不得反向修改任何设置;
- 每次运行保存 config 快照 + run hash(沿用仓库现有机制);
- 失败运行与负结果同样入库。

## 4. 评价体系与注入实验框架

### 4.1 指标层级

| 层级 | 指标 | 说明 |
|---|---|---|
| **主** | coil 域未采样 k 误差 $E_{\text{unobs}}$ | 复数、多线圈、与前向模型同域 |
| 次 | 脑内 PSNR / SSIM / NMSE / HFEN | **统一动态范围**(脑内峰值,非全局离群峰) |
| 补充 | whole-volume SSIM | 注明其差异已实测 100 % 来自脑外背景 |
| **禁用** | 幅值域"零空间误差"、`@max` 跨对比度比较、`comp` 复合分 | 前两者已证不可比;后者是内部搜索启发式 |

### 4.2 参考图像的循环性

同一套 1-map CSM 既定义 GT 又定义前向模型,会抹掉 CSM 模型误差。每个主结果至少在**两种 reference** 下报告:(a) 满采 RSS 或自适应线圈合并;(b) 独立配置的满采 CG-SENSE;并做 1-map / 2-map ESPIRiT 敏感性。**结论若在两种 reference 下翻转,则不得写入论文。**

### 4.3 DC 协议

每个方法同时报 raw 与**同一 DC 算子投影后**的结果,主表声明使用哪个。禁止只对本方法追加后处理。

### 4.4 注入构造(满采复数图像域,加到物体上)

1. $\delta$ 为复数病灶场,**相位取局部组织相位**,不引入人工相位断层;
2. **带限到满采 Nyquist 支撑** —— 合成病灶若含超出采集分辨率的高频,所有方法都会因不可测量成分挨罚,比较被污染;带限后病灶与真实解剖处于同一分辨率世界;
3. $x^{\text{lesion}}_{\text{FLAIR}}=x_{\text{FLAIR}}+\delta$,**T1 完全不动**;
4. 前向 $y=M\odot F(S\odot x^{\text{lesion}})+n$,$n$ 与对照臂使用**同一噪声实现**;
5. **配对对照** $\delta=0$,其余(种子、掩膜、迭代)逐位相同。

### 4.5 扫描维度与指标

- 维度:直径 {2, 4, 8, 16} mm × 相对白质对比度 {低, 中, 高} × 位置 {脑室旁, 皮层旁, 深部白质} × 数量 {单发, 多发}。
- 指标:$P_{\text{keep}}$(保持率)、$L_{\text{leak}}$(跨对比度泄漏)、病灶 CNR、体积偏差、小病灶检出敏感度、**private evidence map 对已知注入位置的检测 ROC**。
- **空病灶臂**($\delta=0$ 走完整流程)标定 private 的**假阳性率**;缺此臂则 evidence map 的可信度无法声明。

### 4.6 横向审计对象

同一注入协议施加于 all-shared MC-GS、SGTV、joint-INR(及可得的 PnP-CoSMo),给出"强制共享类方法的病灶压制与泄漏"横向证据。**这是不依赖 CRISP 获胜的那部分结论。**

### 4.7 真实信号臂(CE pair)

若确认为平扫–增强:增强区域是天然的对比度特异 innovation(存在于 post、不存在于 pre),对其跑同样的 $P_{\text{keep}}$ / $L_{\text{leak}}$,作为 n = 1 真实案例佐证,论文措辞严格限定为 case demonstration。若确认为重复扫描,则关闭该臂并明写 limitation。

## 5. 闸门

| 闸门 | 问题 | 通过线(先于实验写死) | 成本 |
|---|---|---|---|
| **G0 表示天花板** | 高斯表示本身够不够 | 用**满采** k 空间拟合高斯,与满采 voxel CG-SENSE 比 $E_{\text{coil,full}}$;要求高斯在 ≤ 1M primitive 内达到 **≤ 2 ×** voxel 参考值 | ~10 GPU-h,3 例 |
| **G1 强基线入库** | 比的是不是稻草人 | CS-SENSE(TV/wavelet)、LLR、单对比 3DGSMR 等价物全部进仓库,config 冻结,**最优不得落在网格边界** | ~20 GPU-h + 工程 |
| **G2 共享有无空间** | CRISP 前提成立吗 | §3.4 | ~60–80 GPU-h |
| **G3 选择性 vs 强制** | 路由比全共享强吗 | 注入框架上 $\Delta P_{\text{keep}}>0$ **且** 背景保真不降 **且** 泄漏不增 | ~40 GPU-h |

**G0 先跑** —— 对高斯实现最便宜的一枪;若高斯连满采都拟合不好,后续所有"路由"讨论都会被此混杂因素污染。

## 7. 风险、转向与放弃条件

| 风险 | 转向 |
|---|---|
| G0 不过(高斯是瓶颈) | 弃 CRISP-GS,改 voxel / 紧支撑基;方法设计为表示无关,可存活 |
| **G2 两种掩膜条件都不过** | 论文变为"安全审计 + 公平基准";CRISP 降级为"我们也试了路由,无可路由之物" |
| G2 仅互补掩膜下通过 | 结论更强,但需论证互补采样的前瞻可实现性,加一节论述 |
| 注入真实性被质疑 | 带限 + 与真实病灶频谱对比验证 + CE 真实臂 |
| CE 只是重复扫描 | 关闭临床臂,明写 limitation,目标可能下调至 MRM / TMI |
| 候选数爆炸 | 闭式审计已把单候选压到毫秒;必要时 FDR 批量上限截断,并**记录被截断数量**(禁止静默截断) |
| **伦理未覆盖** | **阻断一切涉及 16 例的工作**;优先确认 |

**放弃条件:G0 与 G2 同时不过 ⇒ 本线无方法论文。** 将已有资产转为"公平基线 benchmark + 负结果"论文并收尾,不再投入。此结局须现在接受,否则闸门形同虚设。
