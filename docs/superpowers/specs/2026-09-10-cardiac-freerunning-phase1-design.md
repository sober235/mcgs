## 2. 为什么不是"旧重建代码只换参数"（决定记录）

- MC-GS 与自写的 CG-SENSE / CS-SENSE 臂，前向都是 `fft3c(图像×线圈图)×掩膜`（`paired_gs/trainers/joint_trainer.py:499`）；数据加载要 (C,X,Y,Z) 笛卡尔 k 空间，并从全采样 k 空间生成真值。本数据是 22,000 条方向各异的 3D 径向辐条，没有全采样，两条都不满足。
- BART 的 `nufft`、`pics` 原生支持非笛卡尔，`ecalib` 用网格化后的中心数据即可。前期 L1-ESPIRiT 臂（`Results_20260908/T1T2_AF12_retro/scripts/recon_l1espirit.py`）的 `bart pics` 调用加一个轨迹参数 `-t` 就能用于本数据，所以本阶段的重建全走 BART。
- 不采用"从参考图合成笛卡尔 k 空间，再让旧代码整套换配置跑"。合成数据与重建共用同一线圈模型，属于数据罪（Shimron et al., PNAS 2022），分数虚高，只能当冒烟测试。

## 5. 管线

### 5.1 读取（`cardiac_fr/twix.py`）

- 解析 multi-raid 头，取最后一个 measurement；逐 MDH 前进，SYNCDATA 按头里的 DMA 长度跳过，遇 ACQEND 停。
- 第 0 条（NOISEADJSCAN）另存为噪声样本 `(24, 224)`。其余 176,000 条存为 `raw.h5`：`ksp` 形状 `(8, 22000, 24, 224)` complex64（回波, 辐条, 线圈, 采样），另存 `lin`、`seg`、`eco`、`ts_ticks`。
- 断言：每条 224 点、24 线圈；回波按 0…7 循环；`Lin` 从 0 递增到 21999；总行数 176,000。
- 交叉核对：V07 用作者 MATLAB 读取器（`mapVBVD_JH`，`flagIgnoreSeg=true`，`unsorted`）读同一文件，抽 1,000 条逐位比较，要求完全相同。

### 5.2 读出采样点裁剪

保留采样 3–220（共 218 点），丢弃 0–2 与 221–223。依据：作者清零 0、1、222、223；V07 实测 0–2 异常；为对称多丢 221。丢弃而不是清零，免得重建在 k 空间边缘去拟合零。实施时四例都量一次首尾幅度；若异常超出这个范围，停下来报告。

### 5.3 轨迹（`cardiac_fr/trajectory.py`）

- 移植作者 `phyllotaxis3D.m` 与 `computePhyllotaxis.m`（`flagSelfNav=true`，nshot 1000，nseg 22，N 224）。采样半径 r = −0.5 + j/224（j = 0…223），BART 坐标 = r × 112（图像网格 112³，坐标范围 [−56, 56)）。数组下标 = `Lin`。
- 在 r 单位下与作者 MATLAB 函数输出的 kx、ky、kz 逐点比较，最大绝对差 < 1e-9。
- 去掉 seg 0 的 SI 辐条。图像轴与解剖方向的对应由 R0 重建目视判定，写进 README。（2026-09-12）方位逐例判定并存 `orientation.json[<Vxx>]`：V07/V03/V08 为横断 slab（axis0 右→左、axis1 后→前、axis2 上→下），V04 为冠状 slab（axis0 下→上、axis1 右→左、axis2 后→前）；用到方位的脚本（极性、块视图、图）都按例读取。

### 5.4 生理信号与呼吸门控（`cardiac_fr/physio.py`）

- 全量核对：四例 `TimeStamp_ms` 与 `(ts_ticks − ts_ticks[0]) × 2.5` 逐行相等。
- 每条辐条的呼吸值 = 其 8 行 `respSignal` 的均值；辐条时间 = 回波 0 的时间戳。
- 稳态：丢弃前 10 s 采集的辐条（沿用作者自门控代码的 10 s 阈值；翻转角 12°，每条辐条约 17 ms，前几秒信号未稳）。
- 呼吸门控：按呼吸值排序，取呼气末一端的 1/3 辐条。极性用两条独立判据：(a) 呼吸值直方图的主峰在哪一端（呼气末停留最久）；(b) 两端各取 1/3，按 R0 的设置分别重建回波 3；在肝顶块和心脏块里（逐例放在该例 R0 图上，记在课题 `polarity_boxes.json`；V07 为肝顶 axis0 16–56、axis1 40–80、axis2 56–96，心脏 axis0 36–80、axis1 48–88、axis2 30–80）分别用亚体素归一化互相关测两组沿 SI 的位移；两块方向一致且都不小于 0.5 体素才有效，解剖更靠头侧的一端是呼气末，否则算无法判断（2026-09-11 两次修正，均经用户批准：第一版用回波 0、沿 SI 全长取剖面，被视野边缘亮带主导；第二版用各轴中心 16–95 的整块，被脊柱、肋软骨、胸壁这些不随呼吸动的强边缘主导）。两条一致才采用，不一致就停下来报告。（2026-09-12 第七处修订，用户批准）判据 (b) 的有效门槛从 0.5 体素提到 1 体素（2 mm）：V03 的三分组互相关只有 +0.67/+0.62 体素、肝顶边缘位置反而 −0.42 体素、极端五分之一组也只有 +0.82/+0.89 与 −0.65，全在分辨率以内且符号互相矛盾，而 V07 同样量法为 2.1 到 8.3 体素（`logs/diag/fifths_polarity.log`）。不到 1 体素算无法判断，此时若判据 (a) 的停留不对称（呼吸值上五分之一停留时间 / 下五分之一，`physio.dwell_asymmetry`）≥ 2 指向高端（或 ≤ 0.5 指向低端）则采用 (a)，报告记 basis = histogram、image_criterion = undetermined。V03 另有五分之一组证据（两端膈肌位置差不到 2 mm），属"呼吸门控弱"，呼气末三分组与任意三分组几乎等价。V04 第一次判为"无法判断"（−0.19/−0.07 体素）的原因是方位假设错了：V04 的成像 slab 是冠状的（twix `sSliceArray.asSlice[0].sNormal.dCor = 1`，其余三例 `dTra = 1`），图像 axis0 = 下→上（头在高下标）、axis1 = 右→左、axis2 = 后→前，位移被沿 AP 轴量了。`orientation.json` 自 2026-09-12 起按例存放，块在 V04 自己的坐标系里重放后判据 (b) 得 +2.17/+1.97 体素（高端更靠头侧），与直方图一致（basis = both）。注意 phyllotaxis 的"SI"自导航辐条沿 slab 法向，V04 上它其实沿 AP。V03：停留不对称 2.5，SI 自导航 6 个线圈也指向高端（`logs/diag/si_nav_polarity.log`，此法在 V07 上仅 2 线圈有信号，只作旁证），取高端。
- 心动：由 `cardTriggers` 给每条辐条算 RR 内相位 ∈ [0, 1)，存盘备用，本阶段不用来分组。

### 5.5 线圈图

用回波 0、稳态后的全部非 SI 辐条：`bart nufft -i -x 112:112:112 <traj> <ksp> <coilimg>`（逐线圈图像）→ `bart fft -u 7` → `bart ecalib -t 0.001 -c 0.0 -r 24 -m 1`（与脑部相同参数）。8 个回波共用这一组线圈图。核对：体内线圈图平方和约为 1，目视无卷绕。
（2026-09-11 第五处修订）224³ 网格（见 5.6）另有一组线圈图 `sens2x`：ecalib 逐体素一步约 1 ms/体素，224³ 要 3 小时，故在 448 mm、112³（4 mm）上用 R0 辐条中心 |k| < 56 的采样与同样的 k 范围（`-r 48`，等于 112³ 上的 `-r 24`）算 ESPIRiT，傅里叶插值到 224³ 后按体素归一到平方和 1；核对量 = 归一前体内平方和在 1 ± 5% 内的比例，门槛 0.90（它衡量插值误差，归一化把它去掉）。R0 与极性重建仍用 112³ 的 `sens`。

### 5.6 重建（BART `pics -t`，即前期 L1-ESPIRiT 臂的同一调用）

- **缩放：** 所有重建都加 `-S`，把 BART 内部缩放还原到数据单位。REF 与全部欠采子集重建（5.7）在同一例同一回波上共用一个 `-w`，取 REF 重建时 BART 报告的 `Scaling` 值（默认输出里没有就加 `-d5` 取），保证它们同一标度、λ 同一含义。R0 和 5.4 的极性重建只用来看图，用 BART 自动缩放。
- **R0 运动平均：** 稳态后全部非 SI 辐条（约 20,400 条，AF 约 0.97）× 8 回波，CG-SENSE `-l2 -r 1e-3 -i 100`。用途是验证整条链：解剖、方位、回波间幅值衰减与水脂相位变化是否合理。
- **REF 参考：** 呼气末 1/3（约 6,800 条，AF 约 2.9）× 8 回波，CG-SENSE `-l2 -i 100`，λ 按下一条的正则尺度。
- **正则尺度（2026-09-11 修订，用户批准）：** 径向下 BART 的 AᴴA 最大特征值远大于 1（V07 REF 为 5,617；脑部笛卡尔约为 1），绝对 λ=1e-3 只相当于 1.8e-7 λmax，等于不正则：60 与 100 步体内差 31%、120 与 200 步差 32%，几乎全在细节噪声上。因此 REF 与全部欠采子集的 λ = λ_rel × λmax，λmax 为该例 REF 辐条集的最大特征值（BART `-e` 测，与回波无关，REF 与子集共用）；REF 的 λ_rel 取 {1e-3, 3e-3, 1e-2} 中能通过迭代数核对的最小值，在 V07 上选定后冻结；5.7 的 L1 候选不乘 λmax（见 5.7）。R0 与极性重建只用来看图和测位移，保留原来的 `-r 1e-3`。
- **重建网格（2026-09-11 晚第五处修订，用户批准）：** 220 mm 视野只装下约四成信号。把 V07 REF 数据低通重网格化到 448 mm 上，62% 的线圈合成能量在 220 mm 之外（手臂、侧胸壁、背、上腹），逐线圈视野外占比 0.19–0.87 与逐线圈样本内残差的秩相关 0.86。后果：REF 自己预测留出辐条的 NRMSE 底为 0.452（回波 0）、0.579（回波 4），k 中心 ±3 点内残差 38%，各方法各 AF 之间只差 0.1–1%，留出口径失去分辨力；第二次自检 L1 臂也因此不单调（AF 8 比 AF 12 低 2 dB；λ 按辐条数缩放不能修），证据在课题 `logs/diag/`。梯度延迟已排除：回波 0 峰位平均早 0.28 点且随方向变，但按延迟模型修正轨迹后残差反而升到 0.534。因此 REF、留出与全部欠采子集改在 224³ 网格上重建（448 mm，体素仍 2 mm；2 倍过采样读出本就支持），存盘、指标与图只取中心 112³（220 mm；两个网格都以 N/2 为中心，`cardiac_fr.bart.crop_center`，有单元测试）。V07 回波 0 实测：样本内留出 NRMSE 0.452→0.130，k 中心残差 38%→11%，逐线圈 0.17–0.81→0.08–0.26，视野边缘带/体内幅值 1.84→0.93（`logs/diag/fov2x_test_V07.json`，`figures/V07_fov2x_ref_e0.png`）。λmax 与 `-w` 在 224³ 上重新测（V07 λmax 2,204.6，`-w` 由一步探针或 REF 运行记录）。R0 与极性重建留在 112³（只看图、测位移；图像有折叠）。AF 定义不变（相对 112 采集矩阵）。代价：每次重建约 7.9 倍耗时（REF 一个回波 1,108 s，λmax 探针 364 s）。
- **迭代数核对：** REF 回波 0 的 60 步结果 x60 与 100 步结果 x100，体内 ‖x100 − x60‖ / ‖x100‖ < 1%；不满足就改 200 步重跑。
- **缩放核对：** 同一份 REF 数据分别用 `-w X` 与 `-w 2X` 重建（都加 `-S`，其余同 REF），两者体内幅值之比应为 1（误差 < 1%），证明 `-S` 确实还原到数据单位。

### 5.7 评估口径（`cardiac_fr/gauge.py`）

- **AF 定义：** AF = 19,704 / 实际辐条数，与脑部"相对全网格"的 AF 同义。
- **留出集：** 从 REF 辐条中按固定种子（seed 0）随机取 5%，编号存文件，永不进入任何欠采重建。
- **欠采子集：** 从 REF 去掉留出后的辐条池中按交错整组抽取。池里出现的交错按编号排序后，第 j 个选 round(j × 步长)，步长取使辐条数最接近目标的值。目标 AF 8、12、16，报实际 AF。所有方法共用同一份子集文件。
- **指标**（幅值图，统一除以参考的 P99.9）：
  - 整体：PSNR、SSIM、NMSE，用 `paired_gs.metrics.metrics.evaluate_reconstruction`（与脑部同一实现）。
  - 体内：`diag_artefact.headonly` 的 `head_mask`（|ref| > 0.05 × P99.9，这里叫 body）、`head_psnr`、`head_ssim`、`head_hfen`。依赖脑白质掩膜的 `grain_ratio` 不用。
  - 心脏框：在 V07 的 REF 上目视选一个包住心脏的长方体，坐标写进 README 与 `gauge.json`；报框内 PSNR、SSIM。
  - 留出 k 空间 NRMSE = ‖A_ho x − y_ho‖ / ‖y_ho‖，其中 A_ho = 线圈图 × `bart nufft`（留出辐条的轨迹）。REF 自己的这个值是样本内，单独标注。
- **排名主口径：** 留出 NRMSE。理由：REF 本身 AF 约 2.9、有噪声和条纹，图像指标会偏向与参考同类的 CG-SENSE；留出 NRMSE 不依赖参考。图像指标为辅，并始终配误差图。
- **误差图：** |rec − ref| / P99.9(|ref|)，jet，固定 [0, 0.1]。
- **口径自检**（V07，回波 0 与 4）：CG-SENSE 与 L1 小波（`pics -l1`）在 AF 8、12、16 上重建。L1 的 λ 在 AF 12、回波 0 上按体内 PSNR 从 {1e-4, 3e-4, 1e-3, 3e-3, 1e-2} 中选定后冻结，用 BART 自身数据缩放下的绝对值；CG-SENSE 用 REF 的 λ_rel × λmax。（2026-09-11 核实并经用户同意：L1 的阈值作用在 BART 归一化后的数据尺度上，乘 λmax 会把图像压成零；绝对 λ=1e-3 在 AF 12、回波 0 上体内 PSNR 33.56 dB，高于 CG 的 30.69 dB。100 步 FISTA 并未收敛，100 与 200 步差 27%，200 步反而更差，所以这一臂是早停解，结果随步数变；和脑部课题的 L1-ESPIRiT 一样按 100 步报。）这和脑部课题"在 hyw 上选 λ"的做法相同，对 L1 偏乐观，已注明。要求体内 PSNR、SSIM、HFEN 和留出 NRMSE 全部随 AF 单调变差；不满足说明口径有问题，停下来查。（2026-09-12 第六处修订，用户批准）门改为：主口径留出 NRMSE 对所有臂单调；图像指标只对 CG 臂要求单调（检验指标实现，CG 的误差随 AF 增长）；L1 的图像指标照报并注明「对噪声参考饱和」。依据：224³ 上的自检 CG 8/8 单调，L1 的留出 NRMSE 与 SSIM 单调，体内 PSNR/HFEN 在 AF 8–16 之间只差不到 0.8 dB、不单调，误差主体是 REF 自身噪声（`logs/diag/selfcheck_error_split_V07.log`：L1 三个 AF 的低通/高通误差 0.05–0.06 几乎相同，CG 的误差主要是随辐条减少加重的 Tikhonov 收缩）。对着有噪声的参考，去噪型方法的 PSNR/HFEN 分不开 AF，这正是留出 NRMSE 为主口径的原因。

### 5.8 冻结与批量

V07 的全部核对与自检通过后，把本节所有参数写入课题的 `params_frozen.json` 与 `gauge.json`，再对 V03、V04、V08 跑 5.1–5.6（R0 + REF，8 个回波）。口径自检只在 V07 做；其余三例的心脏框等第二阶段要比较方法时再定。判据 (b) 的肝顶块与心脏块逐例在 R0 图上放好、写进 `polarity_boxes.json` 后再跑。

## 7. 风险与已知限制

- **视野：** 原计划的 112³（220 mm，与作者一致）把 62% 的信号折叠进视野，2026-09-11 已按 5.6 第五处修订改为 224³ 重建、中心 112³ 评估。R0 与极性重建仍是 112³ 的折叠图像，只用来看方位和测位移。
- **心动平均：** REF 里心脏被心动模糊。本阶段的参考是"呼气末、心动平均"状态，不是某一心动相位。
- **参考不是真值：** 见 5.7 的排名主口径。
- **噪声预扫：** 每线圈只有 224 个样本，协方差估计粗。只存不用，不做预白化（与脑部课题一致）。
- **耗时：** BART CPU 耗时未知，V07 实测后写进 README。若单个回波的 REF 超过 1 小时，先报告再决定是否减迭代或用 `-U`。
- **停止条件：** 5.1 的交叉核对、5.2 的采样点范围、5.3 的轨迹核对、5.4 的极性判据、5.6 的缩放核对、5.7 的口径自检，任一不过就停止后续步骤并报告，不绕过。
