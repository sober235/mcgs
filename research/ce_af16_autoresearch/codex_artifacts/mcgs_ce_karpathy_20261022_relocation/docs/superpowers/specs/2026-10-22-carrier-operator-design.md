## Selected approach

Leave the original full Gaussian renderer unchanged. For a supplied selected subset of Gaussian rows add

`delta_x(v) = sum_i G_i(v) rho_i [exp(i 2*pi*f_i dot (v-C_i)) - 1]`.

The operator consumes only the selected rows and produces one complex volume. This is replacement of those atoms by Gabor atoms, not a separate image prior. Both independent contrast coefficients can call the same operator with independent frequencies and shared geometry. Selection and MRI optimizer integration belong to the subsequent route, not this component.

Alternative full replacement requires modifying/rebuilding the historical full renderer and makes baseline parity harder. A voxel-by-all-selected-atoms dense CUDA loop would be too expensive at MRI scale. Use the original detached tile-pair membership convention with a new correction kernel. CPU dense double precision is a tiny-fixture oracle only. No frequency-zero early return may erase frequency gradients.

## Mathematics and interfaces

Tensor axis order D,H,W. `h=shape/2`, `C=(positions+1)*h-0.5`, `d=(v-C)/h`, positive scales `s=exp(log_scales)`, quaternion wxyz normalized as q/(norm(q)+1e-8), M=R diag((s+1e-8)^(-2)) R^T. Envelope exp(-d^T M d/2) inside mahal<=9, otherwise zero, matching historical conventions. Support/tile decisions are detached. Frequency is cycles per voxel, each component strictly within (-0.5,0.5); reject invalid finite/range input. No physical millimeter claims. Use stable `cos(theta)-1=-2*sin(theta/2)^2`.

New public component interfaces (exact names):
- `carrier_reference.carrier_correction_reference(positions, log_scales, rotations, density, frequencies, volume_shape)` -> complex tensor, CPU float64/complex128 reference; supports autograd and zero/nonzero frequencies.
- `carrier_operator.carrier_correction(positions, log_scales, rotations, density, frequencies, volume_shape)` -> complex64 CUDA tensor. Inputs selected K rows: float32[K,3], float32[K,3], float32[K,4], complex64[K], float32[K,3]. All tensors same CUDA device; rank/shape/dtype/finite/frequency checks are explicit. Normal non-contiguous inputs may be made contiguous with autograd preserved. Empty K returns differentiably connected zeros with correctly shaped zero gradients.
- `carrier_operator.load_carrier_extension(build_directory)` explicitly builds/loads only the dedicated extension, returning module plus provenance. No implicit build in production forward and no fallback to another backend. Numeric tests explicitly load it first. Bind sources, binary digest, compiler/version/flags, Torch/CUDA ABI and architecture; keep artifacts under new carrier-owned build path.

Use an independent CUDA autograd boundary over voxel centers, symmetric inverse covariance, complex density and voxel frequency; return gradients for each. PyTorch chains centers/M back to normalized positions, log scales and wxyz rotations. Do not detach these original tensors. The exact VJP formulas and source interfaces are in docs/carrier_feasibility_20261022.md; they are required implementation input. Center gradient includes the carrier phase term -2*pi*w*T*f. Frequency gradient at zero must remain nonzero for asymmetric imaginary upstream loss.

New correction tile bounds conservatively cover the actual M-defined mahal<=9 support: use 3*sqrt(diag(inv(M)))*h axis radii when a reliable finite inverse exists, retaining historical floor/ceil/clamp and stable pair ordering. The old R diag(s^2) R^T bbox is only approximate for norm+epsilon quaternions and epsilon scales; bit-identical old bbox membership is not required for this new operator. For finite but singular/ill-conditioned geometry without reliable inverse, explicitly cover the full finite volume for that atom and apply the exact kernel support test. Reject nonfinite derived geometry before integer bounds or pointer use; clamp oversized valid bounds before unsafe conversions. This conservative bounding policy is not a backend fallback. Include a non-unit quaternion boundary fixture and finite degenerate support case. Ordinary bounded fixtures retain all public-input VJP versus CPUdouble tolerances. For the deliberately near-singular quaternion case, float32 cancellation makes parameter-space relative accuracy ill-conditioned: test support/output and local center/M/density/frequency VJPs against the same rounded geometry in double, and label that limited scope. This is fixed before any CUDA run and does not relax ordinary all-input thresholds. It preserves zero-carrier equivalence, but does not claim identical nonzero-frequency support to historical approximate bounds for pathological inputs. Later MRI integration must disclose the bound policy and independently test G2 zero equivalence.

CUDA launcher must respect current stream/device, check launches, validate input shapes/index/tile arrays before pointer access, and have barrier-safe ragged tiles. Do not inherit thread-dependent barriers from an old implementation. Atom support matches exact mahal<=9 and the historical max_radius parameter never clamps it. Repeated atomic backward roundoff is measured, not hidden.

## Acceptance and exclusions

1. CPU double reference: anisotropic tiny shapes, non-unit quaternions, overlapping signed complex atoms, zero/nonzero frequencies. Compare correction plus ordinary analytic Gaussian against independent direct Gabor sum. Analytic local VJPs versus Torch autograd and central differences for all inputs; finite differences avoid hard-support crossings. Algebraic/autograd rtol=atol=1e-10, finite difference rtol1e-5/atol1e-7. Verify an off-center atom with real density and imaginary output loss has nonzero frequency gradient at zero. Axiswise quarter-cycle/normalized-frequency conversion must catch scaling errors.
2. CUDA microgate uses inspected idle compatible GPU and no MRI data. Compare float32 outputs/all VJPs against CPU double on bounded fixtures at rtol2e-4/atol2e-5. Zero-frequency correction and old-input correction gradients must be exactly zero, while constructed frequency gradient is finite/nonzero. Include ragged tiles, K0/K1/overlap/outside support, noncontiguous inputs, invalid shapes/devices/dtypes/NaNs/frequency bounds and any exposed tile index corruption; refuse invalid input before unsafe kernel work. Repeat atomic VJPs to record max variation. Confirm separate extension loaded from its own build and original binary SHA unchanged.
3. Passing these gates establishes numerical consistency only. No PSNR gain, full-scale performance, original-optimizer trajectory equivalence or safe MRI integration is implied. The next route must separately freeze subset/seed/frequency parameterization/LR/clipping, preserve original seven-state restoration with separate carrier state, add actual zero/control/enabled-smoke and final checkpoint/export proofs, and use frozen three-metric evaluation. New actual MRI mask must not be generated; historical fixed mask remains the disclosed exception.
