# 不同掩膜探针(2026-10-08,用户要求)

问题:平扫和增强各用一张掩膜时,MC-GS 能否拉开与 GS-single 的距离。只针对这一对数据。

- 平扫:原 vdPoisMex 掩膜不动。增强:第二次 vdPoisMex 抽样(accelx 4.40,ACS 强制全采,剪最外 30 点,恰好 2552 点,AF 16.00),
  径向密度与原掩膜几乎一致。每个扫描的加速倍数和扫描时间都不变。
- 两张掩膜 ACS 外各 1976 点,重合 243 点(12%);两扫描合起来覆盖 4285 个位置(同掩膜时 2552)。
- 门:`check_sim.json` 全过;增强零填充 26.99 dB(原掩膜 26.93),两张掩膜难度相当。
- 课题目录 `Results_20260908/CE_retro_cssense_af16_vdpois_cm`(数据软链 vdPoisMex 线;`t1t2_common.Pair` 现在优先读
  `sim/mask/mask_af16_3d_<scan>.h5`,没有时退回共享掩膜,原课题行为不变)。配置 `configs_cm/`,作业表 `ar_jobs_cm.tsv`。
- 跑:MC-GS(定稿配方)、公平 GS-single 增强(新掩膜)、公平 GS-single 平扫(同掩膜,应复现 34.583,当对照)、
  CS-SENSE 增强(新掩膜,λ 0.00025/0.00035/0.0005,掩膜难度对照)。
- 同掩膜参照:MC-GS 34.646 / 36.897,公平 GS-single 34.583 / 36.809,对单臂余量 +0.062 / +0.088。

## 结果(10-08 17:51,头内 PSNR)

| | 平扫 | 增强 |
|---|---|---|
| MC-GS 不同掩膜(同掩膜)| 34.684(34.646)| 36.977(36.897)|
| 公平 GS-single 不同掩膜(同掩膜)| 34.583(34.583,平扫掩膜未变,对照逐位复现)| 36.863(36.809)|
| CS-SENSE 增强 新掩膜(原掩膜)| — | 36.419(36.371)|
| **MC-GS − GS-single 不同掩膜(同掩膜)** | **+0.100(+0.063)** | **+0.115(+0.088)** |

- 新的增强掩膜本身略容易:单臂 +0.054、CS-SENSE +0.048,两者一致。
- 扣掉掩膜难度后,互补采样给 MC-GS 的额外好处:平扫 +0.038(平扫掩膜没变,全靠伙伴扫描看到了不同的 k 空间)、增强 +0.027。
  余量从 +0.06 / +0.09 到 +0.10 / +0.12。副指标同向:MC-GS 两扫描 SSIM / NMSE / HFEN 都优于单臂。
- 不能下结论的地方:只抽了一张新掩膜。两次抽样之间单对比度方法就差 0.05 dB,和这里 +0.03~0.04 的增益同一量级;
  要说"互补采样稳定拉开差距",需要再抽几张增强掩膜(每张 2 个 GS 训练,约 1.3 小时)。抽样也是随机的,不是专门设计的互补图案。

## 设计互补掩膜探针(10-09,增强掩膜 = 平扫掩膜整体错一条 k 空间线)

| | 平扫 | 增强 |
|---|---|---|
| MC-GS(定稿配方)| 34.665 | 36.882 |
| 公平 GS-single | 34.583(掩膜未变)| 36.776 |
| CS-SENSE 增强(新掩膜 / 原掩膜)| — | 36.329 / 36.371 |
| **MC-GS − GS-single** | **+0.082** | **+0.106** |

对照:同掩膜 +0.063 / +0.088,随机第二张掩膜 +0.101 / +0.114。错一条线的"设计"不如随机抽样,
原因是相邻 k 空间点高度相关:增强的采样点紧贴平扫的采样点,ACS 外重合虽然只有 69 点,但带来的新信息比随机位置少。
互补的标准不是重合少,而是离得远。下一步(`_cs2`):抽 40 张随机掩膜,选增强点到最近平扫点平均距离最大的那张。

## 最远随机掩膜(10-09,`_cs2`:40 张 vdPoisMex 抽样里增强点离平扫点平均最远的一张,1.65 像素)

MC-GS(e1b 配方)34.682 / 36.998,公平单臂增强 36.884,CS-SENSE 增强 36.458(原掩膜 36.371,这张掩膜本身容易 +0.09)。
余量 +0.099 / +0.114,与 10-08 的随机抽样(+0.101 / +0.114)相同。结论:随机抽样之间"互补程度"差别很小,掩膜路线给联合模型的
额外好处就是 +0.03 到 +0.04 dB,再挑掩膜没有用。
